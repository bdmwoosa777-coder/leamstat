# GatherScanner v0.12.45 AUTOPATH

Основной режим: ресурс из сети или каталога → большая карта M → ПКМ через
Windows Mouse Keys → игровой автопуть → визуальный поиск и полный сбор.
Изображение и координатная привязка Альтгарда встроены. Ручная отметка трёх
кибелисков больше не нужна.

В журнале пользователя v0.12.44 сразу было MAP_SETUP_REQUIRED. Из-за разрешённого
резервного режима запускался старый патруль стиками вместо автопути. Теперь в
основном режиме такого перехода нет. Если Lua/сеть/карта не готовы, бот ждёт
с понятным статусом, удерживая стики отпущенными.

## Запуск

1. Закройте старый бот. Распакуйте ВЕСЬ ZIP в новую папку, запустите START.bat.
   Прежние Npcap, ViGEmBus, Tesseract и виртуальный Xbox нужны как раньше.
2. В G HUB установите весь GHUB_MAP_MOUSEKEYS.lua, нажмите Save & Run и физически
   G9 один раз. Профиль G502 HERO и G HUB оставьте активными. Старый Lua выключите.
3. Windows Mouse Keys и Num Lock оставьте включёнными. Используется уже проверенная
   пользователем последовательность Num−, пауза 100 мс, Num5.
4. Нажмите «Галочки для автопути», затем «Подключить Xbox». Можно отдельно нажать
   «Проверить новый Lua». При старте ACK Lua теперь проверяется обязательно.
5. Находясь в нужной области фарма Альтгарда, закройте большую карту и нажмите
   Ctrl+F8. Lua открывает M; программа сопоставляет рельеф с встроенным атласом,
   находит белую стрелку и кликает вычисленную точку ресурса.

Ручная настройка миникарты не является привязкой большой карты. Открытая карта
должна быть обычной картой Альтгарда, севером вверх, с видимой стрелкой персонажа.
Если вручную увести карту далеко от персонажа, нужно вернуть её к персонажу.
Распознавание не выдаёт чужую/пустую карту за координаты.

## Галочки

«Галочки для автопути» применяет нужный набор. Несовместимые старые пункты
становятся неактивными, пока выбран основной режим.

Включены:

- Основной режим автопути по встроенной карте Альтгарда.
- Для дальних точек от 80 м сразу лететь при известной энергии от 50%.
- Встроенная сеть, выбор ресурса повторным кликом, продолжение выбранного сбора.
- Приоритет эфира, поиск иконок миникарты, короткий осмотр камеры, защита.
- Автокалибровка камеры — для обычного визуального сбора, не для привязки карты.

Отключены: Qwen и ожидание Qwen, DirectML, память обходов, патруль стиком,
спринт на A, пробный взлёт, отлёт при застревании, старый выход назад после ТП,
записанный выход, старый независимый контроль большой карты и локальные обходы.
В основном режиме эти ограничения применяются и к скопированным старым настройкам.
DirectML и Qwen не загружаются. Возврат к кибелиску можно оставить как резерв.
«Только наблюдение» для настоящей работы выключено.

A для выбора ресурса остаётся. Отключён именно старый спринт с удержанием
левого стика: движение стиком отменяет игровой автопуть.

## Поиск и подход

Постоянный каталог содержит 650 возможных точек эфира и 590 самоцветов Альтгарда.
Живые ID/XYZ ресурсов из сети имеют преимущество. Если их пока нет, используются
возможные места появления из каталога. Наличие ресурса сейчас проверяется в игре.
Своё устаревшее сетевое XYZ для наведения не требуется: положение определяется
по свежей стрелке M и настоящему рельефу карты.

По умолчанию область поиска — радиус 450 м от первой подтверждённой позиции на
карте в этой сессии. Поле «Радиус фарма, м» позволяет выбрать 150–1000 м. Центр
не смещается вслед за каждой целью. Начинайте с нужного участка или лагеря рядом.

Сеть может начать захват после появления персонажа. Отсутствие собственного ID
или непрерывного XYZ само по себе не запускает патруль и не мешает визуальной
привязке карты. Известная чужая зона отклоняется. Начавшийся собственный сбор
имеет приоритет над новым маршрутом.

Во время автопути бот не даёт движение, спринт, прыжки или обычные команды обхода.
Камеру можно двигать. Попадания мобов по пути не заставляют останавливаться для
каждого боя. Прибытие — два чтения до 3 м либо исчезновение надписи с проверкой
положения у цели. У самоцвета после перелёта запрашивается закрытие крыльев, у
эфира они сохраняются для сбора.

После подхода выделяется до 8 с на прежний визуальный поиск ресурса. Уже замеченная
цель/коррекция камеры получают время закончить выбор; собственный сбор доводится
до исчерпания прежним контроллером. Патруль стиками в это окно также запрещён.
Не найден ресурс — следующий переход снова через M. После ТП выход из лагеря
тоже задаётся точкой ресурса на карте, без макрокоманды назад.

Ctrl+F9 из окна игры останавливает бот и отменяет его игровой маршрут коротким
движением. Если игра уже потеряла фокус, отменяющий ввод в другое приложение
не отправляется: вернитесь в игру и остановите маршрут ручным движением.

## Проверки и пределы

Результаты — VALIDATION_RU.md; сведения об источниках — MAP_RESEARCH_RU.md и
assets/atlas/SOURCE-BUILTIN-MAP.md. В этой среде проверены реальные алгоритмы
OpenCV на изображении настоящего атласа с заданным масштабом/сдвигом, логика
управления, Lua и прежняя регрессия. Живой Windows/G HUB/AION2 здесь нет.
Различия изображения/масштаба/HUD на ПК пользователя ещё требуют проверки.
Неудачная привязка блокирует движение и пишет причину, а не запускает патруль.

Пользовательские журналы, кадры, эталоны, настройки и память обходов не включены.
Полная инструкция v0.12.44 сохранена в HISTORY_v0_12_44_README_RU.md.

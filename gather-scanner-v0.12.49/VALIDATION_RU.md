# Проверки v0.12.49 LOCAL

Полный офлайн-набор: 2576 тестов, OK, без пропусков. После последнего
уточнения сброса противоречащей сохранённой позиции выполнен повторный
полный прогон тех же 2576 тестов. Отдельно 49 новых сценариев: OK.

Проверено:

- Прибытие действительно передаёт найденный кандидат прежней машине
  SEARCH → ACQUIRE_WAIT; в момент находки не запускается следующая карта.
- До первого пути завершается рабочая калибровка. Время подготовки камеры
  не съедает бюджет осмотра. Есть конечный предел осмотра и числа кадров.
- Камера разрешена при местном поиске, все переносные оси и пробный взлёт
  исключаются. План только с движением превращается в горизонтальный осмотр.
  Начатый сбор сохраняет прежнего владельца управления.
- Четыре живых ресурса сопоставляются отметкам и дают правильный выбор
  ближайшего к персонажу, а не к центру группы/вида. Две точки,
  вырожденная/повёрнутая геометрия, исчерпанные ресурсы и неоднозначные
  повторяющиеся группы не определяют собственную позицию.
- Свой сбор создаёт приблизительный ориентир, а не записывает фиктивные XYZ
  в сетевое состояние. Движение, старый повтор попытки, другой игрок/карта,
  новый поток, ТП, истечение срока и противоречащий XYZ проверены.
- Проверены реальные опубликованные примеры wire-полей 2a38/2b38/0238:
  свой статус, чужая сущность, чужая цель своего навыка, собственная цель
  чужого навыка. Векторы направления, NaN, усечённые/лишние поля,
  повреждение поздней записи, обратное время и освежение heartbeat отвергаются.
- При неизвестной энергии игровое окно полёта допускает одну проверяемую
  попытку. Продолжающийся автопуть не открывает M только по таймеру.
- Транспорт QUIET v0.12.48 и его проверки проходят без изменения Lua/wire.
  Сохранены рабочий макрос, G5/G9, правило не переключать Num Lock и
  пользовательские настройки. gather_engine.py побайтно прежний.

Сборка: проверены исходные SHA-256 v45/v47/v48, точный перечень различий,
компиляция Python AST, JSON, ZIP CRC, уникальность имён без учёта регистра
Windows, отсутствие unit-тестов/Lupa/Lua/личных данных в архиве патча.

После публикации все четыре файла отдельно скачиваются по закреплённому
commit URL и побайтно сверяются с локальной сборкой; ZIP CRC проверяется
повторно. Эти проверки не являются запуском бота на живой игре.

В среде нет Windows/G HUB/AION2: живой полный бот здесь не проверен.
Готовность непрерывного определения мировых X/Y по текстуре миникарты,
универсальная карта препятствий и видимость всех спавнов сервером
не заявляются. Открытые исходники и различия методов приведены в
NETWORK_RESEARCH_RU.md.

# Отдельный тест Python → текущий Lua → числовой ПКМ

Это диагностика для установленного бота v0.12.47, НЕ новая версия фарма.
Присланный пользователем GHUB_MAP_MOUSEKEYS.lua совпадает по SHA-256 с CLICK 47.1.
В обеих новых попытках есть ACK, но нет подтверждённого игрового автопути.
Поэтому прежнюю замену API нельзя считать исправлением полного канала.

## Одна проверка

1. Полностью закройте бот. Распакуйте ZIP в его папку с START.bat.
   Старые рабочие файлы, настройки и Lua этот архив не перезаписывает.
2. Текущий Lua CLICK 47.1 оставьте включённым. Если он уже слушает команды,
   ничего с ним не делайте. G9 нужен только для включения после Save & Run.
   Num Lock НЕ НАЖИМАТЬ, рабочее состояние Mouse Keys не менять.
3. Запустите TEST_MAP_CLICK.bat. За 8 секунд переключитесь в игру, откройте M
   и наведите курсор на доступную точку на земле рядом с персонажем,
   внутри карты, вне списка слева. Не выбирайте дальнюю скалу/телепорт/значок.
4. Курсор и карту не трогайте ещё примерно 7 секунд. Тест отправит PING
   и ровно один числовой ПКМ, не передвигая курсор, без Xbox, без M и без бота.
   После этого сами закройте карту M и проверьте, пошёл ли персонаж.
5. Рядом с TEST_MAP_CLICK.bat появится map_click_probe.log. Пришлите этот файл
   и сообщите, начался ли автопуть.

## Что записывается

- подтверждение PING и команды ПКМ Lua;
- положение вручную наведённого курсора и название окна;
- наблюдаемые Windows события Num−/Num5/Clear и клавиш канала Caps/Scroll;
- LEFT_DOWN/LEFT_UP и RIGHT_DOWN/RIGHT_UP — какую кнопку увидела Windows;
- ошибки наблюдателя, фокуса или проверки открытой карты.

Наблюдатель не нажимает клавиш, не двигает курсор и не подавляет события.
Обычный набираемый текст не записывается. Журнал остаётся локально, никуда
автоматически не отправляется. Num Lock может быть только прочитан/отражён
в наблюдении: команд нажатия этой клавиши в тесте нет.

ACK не является доказательством правого клика или автопути. Запись Windows
RIGHT_DOWN/UP — отдельное наблюдение, и даже она не доказывает принятие
точки игрой. Если Windows-наблюдатель не запустился, его отсутствие событий
нельзя выдавать за доказательство отсутствия клика.

Тест использует готовое общее окружение установленного бота. Python/пакеты
переустанавливать не нужно. Без рабочей v0.12.47 этот ZIP не запускается.
Основной бот запускать во время теста не нужно.

# Проверка AI Pilot v0.1.3

Полный прогон: 1204 tests, OK, SKIPS 0; Lua protocol: 16 commands OK;
Resource UI and negative CAPTCHA/death: PASS; OFFLINE TESTS PASS.
После финальной проверки отсутствия сетевого источника в HP-hook повторён
целевой модуль AI/HP: 65 tests, OK. Новый guard покрыт отдельным случаем.

Прогоны выполнены в Linux с синтетическими пакетами и локальным HTTP-сервером
фикстур. Windows, реальный Npcap/G HUB, AION2 и настоящий Ollama/GPU здесь не
запускались. Улучшение игровой навигации и устранение сбоев самого Ollama не
подтверждаются этими тестами.

Проверки транспорта подтверждают stream=false, разбор полного HTTP JSON даже
при доставке несколькими фрагментами TCP, требование done=true, отказ при
усечённом JSON/пустом content, сохранение причины ошибки runner из HTTP 500 и
из error-ответа без done. Старые проверки чтения NDJSON в общем клиенте для
других инструментов сохранены; AI Pilot этим путём больше не получает планы.

HP-проверки подтверждают привязку только после двух разных точных падающих
значений HP с одинаковым максимумом и попаданием по тому же единственному
кандидату; перенос свежих ударов в существующий контроллер защиты; включение
HP OCR при неизвестном ID, отключение после прямого/подтверждённого ID и
отсутствие привязки по одному непроверенному варианту OCR. Отдельно проверены:
полное HP, перечитывание одного пакета, одинаковое HP двух игроков, сосед/дух,
NPC/ресурс, отсутствие ударов, регенерация, устаревшие данные, чужой поток,
сохранение прямой идентичности, сброс при смене карты, изоляция snapshot,
новый HP-пакет во время OCR и временное отсутствие совпадающей пары.

Наличие двух согласных вариантов OCR само по себе не гарантирует правильного
чтения HUD. Дополнительно требуется точное совпадение с сетевыми числами и
временем. При отсутствии нужных пакетов или неоднозначности ID не угадывается.
Падение HP не даёт команде Tab/атаки обойти проверку агрессора. Нативный EXE
не изменён: достаточность наблюдаемых HP-пакетов в конкретном запуске нужно
проверить по DEFENSE_WAIT_ID и hud-hp-correlated.

Внутри новой сборки изменены network_state.py/network_feed.py и два hook в
общем GatherEngine. Классическая версия в своей прежней папке не изменена;
для обычного GatherEngine без AI override условия HP OCR остались прежними.
Lua, native_network/acore2_net.exe, модели ONNX, лицензии и settings_gather.json
совпадают с v0.1.2. Default camera 940 ms, model qwen2.5vl:3b.

Архив упакован по явному списку. Новые личные журналы/кадры/сетевые захваты,
ai_last_error.json и прочие локальные отчёты не публикуются. Прежний ZIP
v0.1.2 проверен по SHA и сохранён. История: docs/history/README_AI_V012_RU.md,
VALIDATION_AI_V012_RU.md. Подробности запуска и ограничений — README_RU.md.

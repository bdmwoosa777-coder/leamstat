# Проверка AI Pilot v0.1.2

Полный прогон после изменения протокола: 1180 tests, OK, SKIPS 0.
Lua command protocol: 16 commands OK; Resource UI and negative CAPTCHA/death:
PASS; OFFLINE TESTS PASS. Прогон выполнен в Linux с локальными HTTP-ответами
фикстур, без Windows, игры, GPU и настоящего вывода Qwen.

После последней правки сброса бюджета только при подтверждённом DONE телепорта
повторен весь модуль test_ai_pilot: 41 tests, OK. Новые сценарии проверяют:

- отказ третьему осмотру после повторяющихся look, и в схеме, и в исполнителе;
- доступность движения с конкретным ориентиром и отказ без clear/точки;
- отсутствие принудительной ходьбы при unclear/deep_drop/blocked;
- сохранение бюджета после wait, неудачного клика, отказа взлёта, стирания
  короткой истории; движение с нулевым смещением бюджет не восстанавливает;
- восстановление после измеренного продвижения/подтверждения ресурса и
  подтверждённого DONE телепорта, отсутствие восстановления при FAILED;
- передачу описания сцены в результаты команды и запрет точек HUD/угла;
- 960 px для крупных снимков, отсутствие растяжения 640 px и маску заданий;
- отказ проверки пустого кадра при синтаксически правильном движении;
- read-only разбор сохранённого кадра и отчёт при отсутствии файла.

Сохранены проверки коротких разрешений стиков, отпуска по сроку, остановки,
потери фокуса/сети, несовпадающего ресурса, одиночного клика и передачи
подтверждённого ресурса прежнему сборщику. Основные gather_engine.py,
gamepad_input.py, Lua, сетевой EXE и ONNX совпадают с v0.1.1.

Ограничение поворотов доказано проверками контроллера. Улучшение визуального
понимания Qwen этим не доказано. Настоящий запуск новой схемы на пользовательской
RTX 4080/AION2 и изменение задержки из-за 960 px/большего ответа не измерялись.
Path=clear остаётся суждением модели, не доказательством отсутствия столкновений.

CHECK_AI проверяет API и семантику пустого кадра; это не тест игровой навигации.
CHECK_AI_VIEW снимает один активный игровой кадр для read-only описания/выбора
инструмента. На настоящем Windows этот новый скрипт здесь не выполнялся.
Модели/кнопки в офлайн-тестах подменены; успешная сериализация JSON не выдаётся
за способность модели понимать конкретный проход.

Публикация собрана по явному списку. Новые пользовательские изображения,
ai_last_*.json, журналы, сетевые захваты и локальные отчёты не включены.
Классическая версия, v0.1.0 и v0.1.1 сохранены. История v0.1.1:
docs/history/README_AI_V011_RU.md и VALIDATION_AI_V011_RU.md.

# GatherScanner v0.12.57 COLLECT

Патч поверх установленного v0.12.56. Закройте бот, распакуйте ZIP в ту
же папку с START.bat с заменой файлов и запустите START.bat. Заголовок
и строка HYBRID должны показывать 0.12.57.

Lua v48, G9, AION_MAP_RMB/G5 и Num Lock оставьте прежними. Новых
обязательных галочек нет. Профиль автопути, кибелиск, радиус и наклон
сохранены; settings_gather.json в архиве не заменяется. Карта Альтгарда
и её уточнённая привязка v56 сохранены без изменения.

## Исправлено по последнему логу

1. Камера вблизи эфира. Между короткими UP-командами выполнялось
   полное синхронное распознавание, иногда больше 2 с. Осмотр точки
   прибытия перенесён в быстрый управляющий цикл. Во время действующей
   UP-команды очередной кадр не обнуляет её. Полный диапазон 1200 мс
   при силе 0,45 сохранён; меняется частота команд, не их сила. Фоновое
   распознавание и быстрый детектор подписи продолжают работать, подпись
   немедленно передаёт управление старому выбору/сбору.
2. Дальние цели. Ранее при наличии хотя бы одной живой сетевой цели
   весь каталог исключался. Теперь ближние каталожные места тоже
   сравниваются с дальними живыми точками по расстоянию. Подтверждённые
   исчерпанные точки исключены, дубликат живой точки не добавляется.
   Приоритет эфира и ограничения энергии сохраняются. Каталожное место
   — возможный спавн; оно не выдаётся за подтверждённый живой ресурс.
3. Крылья после автопути. Обработчик ошибочно считал, что запись
   wing_close_pending уже означает отправленную Y. Теперь хранится
   фактическая квитанция команды. Очередь без отправки выдаёт один
   END_AIR/Y сразу при подтверждённых крыльях. Если базовый обработчик
   поставил очередь сразу ПОСЛЕ отправки, повторной Y нет. Исчезновение
   дуги проверяется; не исчезнувшая дуга не называется успешным закрытием.
   Повторные слепые переключения во время падения не добавлены.
4. Случайно выбранный орихаркон. Его собственный сбор принимается по
   фактическому ID/типу, даже если он отсутствует в фильтре поиска.
   Активная попытка не прерывается. Между попытками, только после
   собственного окончания и при неизменном ID, разрешено закрыть
   подтверждённые крылья и вернуть наземный наклон камеры. Новый старт
   попытки отзывает это разрешение. Только эфир относится к воздушным
   ресурсам; остальные известные ресурсы считаются наземными.
5. Продолжение орихаркона. После потери значка бот освобождал ресурс
   через 2,5 с. Для наземного ресурса возвращён ограниченный поиск
   именно его подписи до 8 с, сохранение ID и оставшихся попыток.
   Фоновое распознавание больше не прекращается из-за одной лишь
   собственной сетевой привязки при потерянном значке. Не запускается
   произвольный соседний клик вместо продолжения наземного ресурса.
   Если точку всё же не восстановить, сохраняется предпочтение одного
   возврата по большой карте к недособранному ID, когда его XYZ известны.
   Отложенный возврат после соседнего ресурса тоже учитывается автопутём.
6. Алмаз в таргете на 3 м. Свежий значок был связан с выбранным ID,
   но функция требовала окончания собственной попытки, которая ещё
   даже не началась. Свежая связанная отметка теперь доступна в APPROACH
   для выбранного ID без этой предпосылки. У близкой наземной цели
   допускается ограниченный повтор активации после выбора: неактивный
   сбор, свежая дистанция до 3 м, свежий отслеженный значок, прежний ID,
   неизменный контекст и прежний предел попыток клика. Для активной
   попытки/чужого ID/потерянного значка нажатие остаётся запрещено.

Возврат камеры, отложенный при переходе с эфира на землю, больше не
отсчитывает срок и не вызывает ложное восстановление во время активного
наземного сбора. Его остаток возвращается между подтверждёнными своими
попытками без движения персонажа, потери ID и сброса счётчика попыток.

## Галочки

Новых галочек нет. Главный автопуть, миникарта, сеть, выбор/полный сбор,
осмотр и подготовка камеры работают по прежнему профилю. Старые
DirectML/Qwen-обходы, патруль стиком, ускорение A и пробные облёты
автоматически выключены при основном режиме автопути. Галочка
приоритета эфира сохраняется: ближайший наземный ресурс не вытесняет
эфир, когда настройка отдаёт ему приоритет. Уже начатый случайный
наземный ресурс дособирается независимо от фильтра новых целей.

Подробные проверки — VALIDATION_RU.md. Проверены офлайн-состояния,
реальные тестовые значки и реальные отчёты виртуального Xbox. Запущенной
игры/G HUB здесь нет, поэтому живая работа этой сборки ещё не проверена.

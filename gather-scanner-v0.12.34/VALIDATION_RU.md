# Проверки v0.12.34 REPEAT

Полный набор: 2044 tests, OK, без пропусков, 112.279 с. Добавлено 9 сценариев test_repeat34.py.

Проверяется реальный фоновый метод движка на штатных изображениях надписи
эфира, с перемещением сцены после подлёта. Подготовка свежей маски букв
проверяется ещё во время active, без общего OCR в потоке ввода. После
сброса selected и окончания подготовленная маска позволяет отправить ровно
один следующий клик, сохраняя ID и режим GATHER, без восьмисекундного ожидания.

Отдельно проверены восстановление имени при найденной общей эмблеме,
отказ от клика при исчезнувших буквах, смена режима во время вычисления,
смена ID при том же имени, старт необязательной проверки до первого кадра
мини-карты, пустые/None имена и фильтрация имён перед OCR-процессом.
Прежняя проверка активного наблюдения обновлена: в фоновом потоке теперь
разрешена местная проверка букв, а общий OCR по-прежнему запрещён в тесте.

Независимый повтор одного сценария на опубликованных исходниках v0.12.33
и новых исходниках: старая версия возвращает glyph=None, затем 0 кликов;
новая возвращает свежие буквы, затем 1 клик, привязка (тестовый ID) сохраняется
в обеих версиях. Наблюдаемая доставка 0.16 с — виртуальное время подставного
контроллера. Это воспроизведение алгоритма, не игровой бенчмарк.

Все прежние проверки фокуса, CAPTCHA, сети, собственного окончания,
неповторения ввода во время текущей нижней шкалы, запрета неподтверждённых
общих значков, ограничений управления и отсутствия глобального OCR на
потоке ввода сохранены. Тайм-ауты и пороги свежести не ослаблены.

Веса моделей, зависимости, настройки, бинарники и формат записей выхода
не менялись. Сборка сверяет неизменённые файлы с опубликованным v0.12.33,
проверяет Python/JSON, дубликаты методов, CRC, обратное чтение ZIP и SHA256.
Архив включает 356 файлов по allowlist предыдущей публикации с тремя
добавлениями: тестом и двумя историческими документами. Новый журнал,
пользовательские маршруты, runtime-файлы, снимки и кэши исключены.

Публикуются ровно ZIP, README_RU.md, VALIDATION_RU.md и SHA256SUMS
в новой ветке downloads/gather-scanner-v0.12.34; main не меняется.
Публичные прямые ссылки сверяются по байтам перед выдачей.
Windows, AION2, физический контроллер и модели на GPU здесь не запускались.

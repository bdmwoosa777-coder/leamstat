# Проверка сетевых источников AION2 для GatherScanner

Проверены публичные README, дерево и указанные ниже файлы на 8 ноября 2026 года. Целевая версия пользователя — Global EU/NA. Это анализ исходников, не запуск перечисленных приложений в игре и не проверка их на текущем клиентском патче. Отсутствие нужного события в просмотренном модуле не доказывает, что его нет во всём проекте.

## Что меняет подход

1. Определять ресурс по ID и реально полученному профилю, а экраном искать точку выбора. Зелёная галочка пера не должна создавать сетевой ресурс.
2. Отдельно подтверждать свой actor ID и выбранный узел. Чужой сборщик рядом не должен разрешать наш повтор F.
3. Разрешать повтор F по подтверждённому началу своего сбора. Выбранная цель, наличие координат и окончание чужой попытки — разные события.
4. Читать текущую/максимальную энергию из поддержанного профиля, сохраняя время последнего обновления. Пока максимум/идентичность неизвестны, значение неизвестно.
5. Запускать защиту по ударам с target=наш actor ID, а не по DPS-сводке или одному изменившемуся пикселю HP.
6. Не объявлять застревание по старой сетевой позиции: сервер может не присылать непрерывное отражение собственного движения. Сетка проходимости и направление камеры из этих данных не следуют.

Приоритет: a2kit как MIT-транспорт/SDK, MIT-каталог Aion DPS и проверка наблюдений GatheringSignal Helper на своей записи. Готовую сводку любого DPS-метра нельзя напрямую превращать в команды бота.

## Ограничения совместимости

- Global — подходящий регион для исследованных реализаций, но поддержка конкретного патча ещё не проверена на пользовательской записи.
- В разных декодерах различаются представление HP/FP, номера полей и нормализация. Нельзя механически смешать их константы.
- Helper по умолчанию пассивно читает поддержанные данные. Его необязательный «Exact distance» — другой механизм: чтение ключа сессии из памяти для исходящего движения. Для приложенной диагностики он не требуется и не используется.
- Справочник точек не доказывает присутствие ресурса. Пропажа объекта из области видимости не равна полному истощению.

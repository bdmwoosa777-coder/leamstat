# Camera Pitch Calibration v0.3 — удобный взгляд чуть сверху

По последнему замеру тест 14 (600 мс при силе 0,45) почти подходит. Нужно немного больше движения вниз: камера должна смотреть чуть ниже горизонта, чтобы при большом отдалении лучше видеть землю. Это и есть цель текущего подбора; точное горизонтальное положение не обязательно.

Добавлены **610–700 мс с шагом 10 мс**, сила везде **0,45**. Сохранён прежний 14 для сравнения. По умолчанию выбран **16 — 620 мс**.

## Запуск и замер

1. Закройте старый тестер и сборщик: горячие клавиши общие. Остановите Lua сбора, если он включён. Для теста Lua не нужен.
2. Распакуйте в новую папку и запустите `START.bat`, подключите виртуальный Xbox. Python и ViGEmBus остаются прежними. Если не хватает библиотек Python — `INSTALL_ONCE.bat`.
3. Режим оставьте **«Верхний предел → вниз»**. Перед **каждым** замером вручную поднимайте камеру до самого верхнего упора и ждите её остановки. Стойте на земле в том же месте. Чувствительность, режим камеры, дистанцию/масштаб и инверсию оставляйте как при предыдущих замерах.
4. В активном окне игры нажмите **Ctrl+F8** — один импульс выбранного номера. Альтернатива: кнопка запуска через 3 секунды и переключение в игру.
5. Начните с **16 (620), 17 (630), 19 (650)**. Если нужна промежуточная точка, используйте 18 (640). Остальные значения доступны в таблице.
6. Оценивайте удобство вида: «ещё высоко», «то что надо, чуть сверху», «уже слишком низко». Градусы не нужны. Перед новым номером снова вручную верните камеру до верхнего упора.

**Ctrl+F9** — отпустить стик и отменить ожидание. **Ctrl+F10** — выбрать следующий номер без движения камеры. Повторные Ctrl+F8 во время теста не создают очередь. Потеря фокуса прерывает импульс. Независимый контроллер также освобождает стик после заданного времени. Его предел увеличен до 700 мс: новые импульсы не обрезаются на прежних 600 мс.

Камера сама не возвращается к верхнему упору. Автоматическая установка рабочего положения в сборщике по этим значениям ещё не включена — сначала выбираем подходящее значение.

## Результаты

Впишите заметку для последнего теста и нажмите «Записать». «Скопировать результаты» копирует данные для чата. CSV/JSON сохраняются локально в `results`, ничего автоматически не отправляется. Пример: «16 — чуть не хватает; 17 — уже хорошо; 19 — удобнее всего».

Заданная и фактически переданная длительность записываются отдельно. Последняя измеряется между отправкой и освобождением виртуального стика; это не измерение угла камерой. Разница в 10 мс невелика, поэтому близкие варианты можно повторить из того же верхнего упора.

Необязательная галочка сохраняет полные кадры до/после локально в `results`; она по умолчанию выключена. При необходимости приложите `after`-кадры и результаты CSV/JSON. Сам тестер изображения никуда не загружает.

Другой режим («Нижний предел → вверх») сохранён для обратных замеров. Для текущего подбора используйте верхний предел. Инверсию меняйте только при действительно обратном направлении и отмечайте это в результате.

Тест управляет только вертикальной осью правого стика. Ходьба, поворот по горизонтали, клики, A/F/V не используются.

Проверка без игрового ввода: `python -m unittest test_pulse -v`. Проверяются все 11 значений и фактическое освобождение, в том числе значения больше 600 мс, нулевое движение/поворот/кнопки, потеря фокуса, остановка и ограничения параметров. Отклик игры проверяется пользователем.

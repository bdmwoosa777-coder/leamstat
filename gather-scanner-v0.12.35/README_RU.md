# GatherScanner v0.12.35 OWNED

Исправление продолжения уже начатого ресурса, когда ник персонажа или
название духа закрывает название эфира. Закройте старую программу, весь ZIP
распакуйте в новую папку и запустите START.bat. Модели/драйверы и запись
выхода переустанавливать не нужно. Сохраните свой рабочий наклон камеры.

## Изменение продолжения сбора

В v0.12.33–34 отсутствие свежих букв могло вызвать CLICK_WAIT, восстановление
камеры и CONTINUATION_RELEASE, хотя свой ресурс ещё имел попытки. Обновления
образца надписи оказалось недостаточно: надпись физически перекрывается
интерфейсом персонажа/духа. Название между попытками больше не обязательно
для виртуального Xbox с обычным событийным режимом сбора.

Теперь значок связывается с сетевыми flow/owner/actor/gather_time во время
ACTIVE собственного сбора, когда выбран именно этот ID. Начальная точка
подтверждается видимой собственной выделенной эмблемой, свежей подписью
либо маленьким местным смещением ранее выбранного значка. Произвольная
общая эмблема после сброса selected в 0 не может начать новую привязку.

После подтверждённого собственного окончания используются оставшиеся
попытки и этот трек. Перед каждым кликом значок заново проверяется на
текущем кадре в маленьком участке изображения. Его рисунок обращён к
камере: отслеживается смещение/небольшой масштаб, не читаются перекрытые
буквы. Поиск ограничен, несколько конкурирующих совпадений отклоняются.
Нет повторного щелчка во время текущей частичной нижней шкалы. Одно своё
окончание даёт один запрос следующей попытки; доставка A не считается
подтверждением её начала. Продолжение ждёт реального сетевого события.

Используется явный клик по значку через курсор LB+LT+A. B/контекстное F
для этого НЕ нажимаются: они могут подобрать лежащий рядом лут. Старые
координаты без свежего совпадения значка не используются. Если меняется
ID/персонаж/соединение, ресурс исчезает или сам значок теряется, старый трек
не становится разрешением на слепой клик по соседнему ресурсу. При потере
самого значка сохраняется ограниченное восстановление вместо вечного
ожидания. Новое обнаружение и первоначальный выбор ресурса по-прежнему
требуют распознавания его названия и проверки ID.

Во время обычного собственного сбора не запускается общий OCR ради имени;
быстрый цикл поддерживает уже найденный трек маленьким сопоставлением
изображения. Это уменьшает зависимость продолжения от фонового OCR.
OWN_MARKER в журнале означает привязку трека к собственному ID, а не
получение координат объекта из памяти игры.

## Близкий самоцвет при приоритете эфира

В отдельной необязательной функции также убрана B. Подсказка «Сбор» остаётся
условием доступности, но действие — нормальный точечный выбор конкретного
значка с обычными проверками курсора и сетевого ID. Приоритет эфира
обходится только на время выбора этого одного разрешённого кандидата;
после выбора или ошибки исключение снимается. Самоцвет обслуживается
до завершения по прежним правилам, затем возвращается приоритет эфира.
Галочка по умолчанию выключена. В интерфейсе она теперь подписана
«Исключение: один самоцвет рядом при подсказке Сбор, выбор значка без B».

## Проверки и ограничения

Реальные шаблоны значков проверены с закрытыми буквами, небольшим смещением
камеры, пропажей значка, соседней эмблемой, устаревшим кадром, сменой ID,
владельца и собственного результата. Проверено, что реальные классы ввода
с подставным устройством отправляют A и не отправляют B. Подробности и
полный набор — VALIDATION_RU.md. Настоящие AION2/Windows/Xbox здесь не
запускались. Новые пользовательские изображения просмотрены в сообщении;
пиксельные тесты используют штатные образцы и искусственное перекрытие.
Веса моделей, драйверы, Qwen и остальные настройки этой версией не менялись.

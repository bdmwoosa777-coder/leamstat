# Проверка кнопки A в AION2

[Скачать ZIP с тестом](AION2_Gamepad_A_Test_v0_1.zip?raw=true)

Отдельная программа для Windows: виртуальный Xbox 360 отправляет ровно одно A после задержки. Есть отмена через Esc, проверка активного окна AION2 и журнал подтверждения через Windows XInput. Приём кнопки игрой проверяется вручную.

1. Распакуйте ZIP и прочитайте `README_RU.txt`.
2. Установите ViGEmBus по официальной ссылке из инструкции, если его ещё нет.
3. Запустите `INSTALL_PYTHON_PACKAGE.bat`, затем `RUN_TEST.bat`.
4. Отключите приёмник F710, подключите виртуальный геймпад в программе и запустите игру.
5. Запустите одно A после задержки, вернитесь в игру, удерживайте физический Alt и наведите мышь на ресурс.

Драйвер не включён в архив и автоматически не устанавливается. Проверены логика импульса и отмена на имитации устройства; реальная игра и Windows-драйвер в среде подготовки недоступны.

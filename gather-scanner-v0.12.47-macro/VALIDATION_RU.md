# Lua MACRO v0.12.47.2: проверка

7 целевых тестов, OK. Настоящие MapKeyWire/MapMouseKeys v0.12.47 и новый Lua
исполняются совместно в виртуальном времени; PlayMacro/AbortMacro являются
имитацией SDK G HUB. Проверены PING → M → один PlayMacro → M, серия отдельных
команд без повторов, имя AION_MAP_RMB, ACK после паузы 500 мс в пределах
таймаута Python 850 мс, исключение SDK без ACK, AbortMacro при отзыве
разрешения, отсутствие любых нажатий Num Lock. Прямой цифровой API Lua
в имитации запрещён: он не является запасным способом клика.

В реальной игре пользователь подтвердил G5 и отдельный G9-Lua PlayMacro.
Полный новый приёмник здесь не проверен на Windows/G HUB/AION2: они недоступны.
Имитация SDK проверяет вызовы/протокол, не воспроизводит USB и поведение игры.
ACK означает вызов макроса и выдержанную паузу, не успешный игровой автопуть.
Синтаксис Lua/Python, байты архива, CRC и SHA-256 проверены.
Рабочие файлы Python v0.12.47, карта, настройки и сеть не изменены.
Пользовательские журналы, кадры и файлы не включены.

# Lua MACRO v0.12.47.2 — для рабочего Python v0.12.47

Пользователь подтвердил обычный макрос G HUB AION_MAP_RMB как с физической
G5, так и из отдельного Lua через PlayMacro по G9 с задержкой. Этот же вызов
PlayMacro("AION_MAP_RMB") подключён к команде ПКМ от Python в полном приёмнике.
Прямых PressKey/PressAndReleaseKey для Num−/Num5 в нём больше нет.

## Установка

1. Бот остановите. Проверенный макрос AION_MAP_RMB и его назначение G5
   оставьте как есть: один запуск без повтора, Num−/100 мс/Num5.
   Он должен находиться в том же постоянном профиле, что и Lua.
2. Из архива возьмите GHUB_MAP_MOUSEKEYS.lua. Вместо короткого теста вставьте
   его полное содержимое в активный Lua G HUB, нажмите Save & Run, затем G9.
   Должна появиться строка `[MAP MACRO 47.2] G9 ARMED`.
3. Запускайте прежний бот v0.12.47. Python/настройки/галочки не менять.
   Г9 теперь включает постоянный приёмник один раз, а команды клика приходят
   от Python. G5 остаётся ручным запуском обычного макроса.

Num Lock НЕ ТРОГАТЬ: ни Python, ни этот Lua его не нажимают.
Карта, сбор/бой через Xbox, статистика, 1200 мс камеры и галочки не изменены.
Имитация мышиной кнопки G5 не используется: вызывается макрос по имени.

В журнале G HUB при команде Python будет `[MAP MACRO 47.2] PlayMacro
AION_MAP_RMB dispatched`. Это подтверждение вызова SDK, а не игрового пути.
После старта макроса до ACK выдерживается 500 мс тишины канала, чтобы не
отправлять Caps одновременно с коротким макросом. Это не чтение фактического
состояния макроса. Обычный макрос должен оставаться коротким и без повтора.
Если разрешение отозвано во время ожидания, вызывается AbortMacro, ACK нет.
Ошибка API также не выдаётся за исполнение. Цифрового запасного клика нет.

Полная работа нового приёмника в игре ещё требует проверки: подтверждён
пользователем отдельный PlayMacro-тест. Старый TEST_MAP_CLICK.bat тоже
совместим, если понадобится проверить одну команду без навигации.
Архив содержит только новый Lua, инструкции и регрессионные тесты,
не полный бот. Он рассчитан на уже установленный Python v0.12.47.

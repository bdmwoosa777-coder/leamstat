# GatherScanner v0.12.2 — цель ресурса, эфир в полёте и выход из ошибки карты

Полный архив для замены всей папки. Основа — v0.12.1 с управлением Xbox без Lua.
Это исправление контроллера и его приоритетов; новая обученная модель не добавлялась.

## Установка

1. Остановите старый бот через Ctrl+F9 и закройте его.
2. Распакуйте ВЕСЬ ZIP в новую папку, выполните SETUP.bat, затем START.bat.
3. В заголовке должно быть v0.12.2. Физический F710/USB-приёмник отключите.
   Старый Lua-приёмник выключите. G HUB и G9 для обычного запуска не нужны.

Камера по умолчанию 940 мс. Старые настройки поверх новых переносить не нужно.
Npcap, ViGEmBus и Tesseract остаются прежними. Окружение Python общее:
%LOCALAPPDATA%\ACore2Gather\runtime\py3xx-хеш. С неизменными requirements.txt
оно используется повторно. Модели ONNX и установленные веса Ollama прежние;
повторно скачивать qwen2.5vl:3b при обычной замене папки не нужно.
Ctrl+F8 — запуск, Ctrl+F9 — стоп.

## Что исправлено

- Замеченный в полёте эфир больше не передаётся обработчику, который сразу
  закрывает крылья. Проверка свежей подписи получает ограниченное время,
  отложенные повторные закрытия отменяются, затем используется штатный выбор.
  Проверяется вся цепочка быстрых обработчиков до ACQUIRE_WAIT и клика.
- Ракурс кадра теперь хранится с номером калибровки. Если калибровка закончилась,
  пока распознавалось название, старая величина наклона не разворачивает новую
  камеру обратно. Перед кликом всё равно нужна текущая подпись/ромбик.
- Если распознавание заняло 0,8–1,5 с, оно может остановить обзор только после
  дополнительного подтверждения на текущем кадре. Старый исчезнувший глиф
  не даёт разрешения на A.
- В свободном поиске одна переданная Y не повторяется через 1,5 с по одной
  оставшейся дуге: во время падения это могло вновь раскрывать крылья.
  Через 3 с непроверенное закрытие освобождает обработчик для поиска;
  новая свободная команда закрытия ограничена паузой 8 с. Исчезновение дуги
  не выдумывается. Для подтверждённого сбора и возврата сохранены отдельные правила.
- 90 с без добычи сами по себе не запускают взлёт. Используется отдельный
  watchdog застревания по перемещению. При неизвестных данных его запасной
  срок остаётся ограниченным. Возврат после трёх минут без результата сохранён.
- Визуальный обход больше не сбрасывает таймер сближения с ресурсом каждый кадр.
  Цель должна действительно становиться ближе. Начатый короткий обход удерживает
  направление в мировом курсе при смене локальных ID путей.
- На шероховатой, но связной земле сохраняется прямой курс миникарты, если
  наблюдения допускают его. Направление цели сзади больше не превращается
  из-за формулы в направление вперёд. Подтверждённый край не разрешает прямой шаг.
  Осмотр уже неудачного курса ограничен по времени.
- Для близкого эфира обзор начинается немного раньше: радиус 18 пикселей при
  базовом масштабе миникарты, с верхним ограничением. Это не расстояние в метрах.
- Новый подтверждённый сетевой удар проверяется перед спасением и другими
  манёврами. Спасение может уступить защите управление. Поиск выбранного
  агрессора допускает до 8 смен цели вместо жёстких 3. Шесть старых эпизодов
  свободного патруля больше не отключают его защиту навсегда. Атака требует
  собственного ID и совпадения выбранного ID с источником реального урона.
- Прокрутка карты сначала даёт указателю установиться, затем отдельно удерживает
  LT и лишь после этого двигает правый стик. Срок движения списка увеличен.
- Если до подтверждения телепорта список не прокрутился, бот один раз закрывает
  карту, проверяет игровой экран и продолжает поиск с задержкой следующей попытки
  возврата. Неудача не объявляется успешным телепортом. При загрузке/неизвестном
  экране движение не возобновляется. Если B уже подтверждала телепорт и прибытие
  неизвестно, сохранена явная остановка вместо повторного расходования свитка.

## Qwen и навигация

Миникарта задаёт цель. SegFormer и Depth Anything оценивают текущие проходы,
Qwen предлагает коррекцию пути в фоне. Ответ модели перепроверяется по текущему
графу; старые пиксели и произвольные игровые команды не исполняются.

Для моделей с thinking новый запрос отключает его так же, как основной анализатор;
бюджет короткого ответа увеличен со 96 до 192 токенов. Пустой ответ теперь сообщает
причину завершения, количество токенов и длину thinking вместо общего сообщения
JSON. Часть ошибок прежнего запуска нельзя точно объяснить без сырого ответа;
успешная реальная работа Qwen этим офлайн-изменением не доказана.

HYBRID_AI_RESULT означает полученный совет, HYBRID_NAV — фактический выбор пути.
Ошибка модели не запрещает миникарту, распознавание ресурса, защиту и сбор.
При отказе соединения сохраняется запуск уже установленного локального Ollama.
CHECK_ANALYZER.bat — отдельная проверка, отчёт hybrid_check.json.

## Кнопки и курсор

Стики — ход/камера; LB+LT — курсор; A в этом режиме — клик по ресурсу.
Голая A в мире запрещена: она делает рывок даже на месте. Автоподход к ресурсу
уже использует автоспринт, отдельная A для ускорения не нажимается.
RS — цель, RB — одиночный навык, X — прыжок, Y — крылья, Start — карта.
В подтверждённом меню A выбирает строку/значок, B подтверждает проверенный телепорт.
RT/AOE не используется, автоматическая посадка на маунта через LS не включена.

Физическая мышь не нужна. Указатель позиционируется программно через Windows
SetCursorPos с чтением позиции. Внутренние ALT_DOWN/ALT_UP — совместимые имена
LB+LT, Windows Alt в обычном транспорте не нажимается. Первый клик по ромбику и
повторы следующих попыток регулируются сетевым состоянием, ромбик во время
активного сбора не спамится. Постоянного B/F нет.

Резервный control_transport="lua" в settings_gather.json сохранён для диагностики.
Только для него нужен прежний Lua. По умолчанию control_transport="xbox".

## Журнал, место на диске, проверки

gather.log в папке бота сохраняется после закрытия и дописывается при запуске.
ETHER_SIGHT — остановка обзора на подписи; AIR_CLOSE — отказ повторять Y при
неподтверждённом закрытии; MAP_RECOVER — проверяемый выход из неудачного возврата.
Новые личные журналы, полные кадры и сетевые захваты в ZIP не включены.

Старые ZIP/папки и ненужные debug_gather/debug_clicks можно удалить после закрытия
бота. Общий runtime при обновлении удалять не нужно. Кэш pip очищают командой
py -3.12 -m pip cache purge. Модели показывает ollama list; ненужную удаляют
ollama rm ИМЯ. Для этой версии оставьте qwen2.5vl:3b.

Результаты — VALIDATION_RU.md. Живой Windows/AION2 с GPU здесь не запускался.
Офлайн-проверки не доказывают узнавание каждого эфира или правильный обход
каждой скалы. Относительная глубина не является точной высотой в метрах или
3D-картой столкновений. Памяти маршрутов и обучения весов между запусками нет.
История предыдущих выпусков — HISTORY_v0_12_*.

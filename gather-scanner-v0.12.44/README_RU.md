# GatherScanner v0.12.44 MAP

Добавлен игровой автопуть через большую карту M и проверенную пользователем
связку G HUB → Num− → Num5 → Windows Mouse Keys. Сбор и управление крыльями
остаются на Xbox. Камеру перед каждым переходом выравнивать не нужно.

Для Альтгарда подключён полный справочник возможных мест появления:
650 точек эфира и 590 самоцветов. Живые сетевые ID/XYZ имеют преимущество;
справочник помогает искать ресурсы, которые ещё не попали в сетевую видимость.
Точка справочника не подтверждает наличие ресурса сейчас. Подробности источников —
MAP_RESEARCH_RU.md и assets/atlas/SOURCE-COMPANION.md.

## Установка

Распакуйте ВЕСЬ ZIP в новую папку, старую программу закройте. Запуск — START.bat.
Прежние Npcap, ViGEmBus, Tesseract и подключение виртуального Xbox сохраняются.
Новых моделей и второго сетевого захвата нет. Qwen для автопути не требуется.

1. Оставьте Windows «Управление указателем мыши с клавиатуры» включённым.
   Включите Num Lock, если у вас выбрано «только когда включён Num Lock».
2. В постоянном профиле G502 HERO замените прежний Lua на
   **GHUB_MAP_MOUSEKEYS.lua**. Старый GHUB_GATHER_SCANNER.lua одновременно не запускайте.
3. Один раз нажмите и отпустите **кнопку мыши 5**: это включает новый приёмник.
   Повторное нажатие выключает его. G HUB и профиль оставьте активными.
4. В программе нажмите **«Проверить новый Lua»**, переключитесь в игру.
   Через 3 с отправляется только PING. Нужен ответ об ACK Lua.
   Сам ACK подтверждает исполнение скриптом, движение проверяется отдельно.
5. Нажмите **«Автопуть: настроить карту»**. За 5 с переключитесь в AION2,
   остановитесь и откройте M. В кадре должны быть область фарма, стрелка
   персонажа и три разнесённых фиолетовых кибелиска. Пройдите подсказки настройки.
   Подробный порядок — MAP_NAV_RU.md. Это однократная привязка карты к координатам.
6. Подключите Xbox, включите **«Автопуть игры по большой карте»**, запускайте бот.
   Без сохранённой настройки и ACK нового Lua действует прежняя навигация.

## Поведение

- Бот находит положение персонажа по стрелке на свежем кадре M, сопоставляет
  рельеф с сохранённым эталоном, переводит XYZ ресурса в точку карты и кликает её.
  Учитывается текущий масштаб/сдвиг. Точки за пределами подтверждённого вида не кликаются.
- После закрытия карты идёт игровой автопуть. Левый стик, спринт, прыжки и
  обычное патрулирование не вмешиваются. Камера доступна. Попадания мобов
  по дороге не отменяют автопуть и не запускают бой на каждом ударе.
- Короткий путь и выход из лагеря — пешком. Опция «Для дальних точек от 80 м
  сразу лететь» заранее открывает крылья при известной энергии от 50%.
  Если игра показала именно вопрос «Невозможно переместиться по земле.
  Переместиться с помощью полета?», бот подтверждает его отдельной F при
  достаточной энергии. F для сбора/лута не возвращена.
- Если измеренный наземный маршрут сильно длиннее прямого, допускается один
  подтверждённый переход на полёт к той же точке. Это не повтор сомнительного клика.
- При двух свежих показаниях «Автоперемещение» с остатком до 3 м начинается
  сбор/посадка. При исчезновении надписи прибытие дополнительно проверяется
  по положению на карте. Ошибка OCR не считается нулевым расстоянием.
- После перелёта к самоцвету/точке облёта бот запрашивает складывание крыльев
  штатным контроллером. У эфира оставляет их для сбора. Три оставшиеся попытки
  начатого ресурса обслуживает прежний сетевой контроллер; новый маршрут не
  начинается во время собственного сбора.
- После ТП и подтверждённой загрузки готовый новый модуль ведёт к отмеченной
  точке за воротами. Если новый Lua ещё не готов, сохранён выход v0.12.43:
  1,2 с назад-вправо, затем назад до общего установленного времени 13–14 с.

Нажимайте Ctrl+F9 для остановки из окна игры: бот отменяет свой автопуть коротким
движением и освобождает ввод. Если фокус уже у другого приложения, ввод туда
не отправляется; игровой автопуть может продолжиться. Остановите его движением
в игре. Обычное отпускание стиков само по себе автопуть не отменяет.

Полная инструкция и ограничения — MAP_NAV_RU.md. Проверки — VALIDATION_RU.md.
В этой среде нет живой Windows/G HUB/AION2: фактический интегрированный клик,
маршруты и скорость фарма ещё нужно проверить в игре. ZIP не содержит ваших
журналов, кадров, личной калибровки или памяти обходов. Предыдущая инструкция
сохранена в HISTORY_v0_12_43_README_RU.md.

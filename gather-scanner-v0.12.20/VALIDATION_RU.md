# Проверка GatherScanner v0.12.20

Полный прогон: 1734 tests, OK, без пропусков.
Среда: Linux/Python 3.12, OpenCV с одним CPU-потоком, Tesseract rus/eng,
тестовые сеть/HTTP/Xbox, настоящий spawn/IPC. Живая Windows/AION2 не запускалась.

Журнал второго запуска v0.12.18 подтверждает продолжение стиковых команд,
замедление чтения миникарты до 2–3 секунд с малым CPU-временем главного потока,
ложную подпись «Войти» и истечение срока курсора. Вода заявлена пользователем;
журнал не содержит достоверного состояния плавания. Причина задержек Windows
не устанавливается только по отношению CPU/прошедшего времени.

15 новых проверок:

8 тестов test_background_runtime.py проверяют:

- структуру PowerThrottling из трёх uint32, точно 12 байт;
- замену IDLE/BELOW_NORMAL на NORMAL, отключение исполнения с ограничением
  скорости и восстановление исходных значений;
- сохранение прочих флагов энергополитики;
- отсутствие изменения NORMAL/ABOVE_NORMAL/HIGH/REALTIME;
- отказ Set API не считается применением и не создаёт ложного восстановления;
- неподдерживаемый GetProcessInformation не ломает очистку приоритета;
- поздние внешние изменения не затираются при завершении;
- повторные start/close и повторное использование не дублируют восстановление.

7 тестов test_ui_caption_guard.py проверяют:

- настоящий _acquire_caption_matches отклоняет «Войти» и запоминает рисунок букв;
- известные подписи UI с пробелами/пунктуацией отклоняются;
- нечитаемая настоящая подпись сохраняет прежний путь выбора;
- подтверждённый Эфир разрешён;
- настоящий click_candidate с «Войти» завершается до вызова gamepad.tap_a;
- доля воды измеряется в ближней области мира, не по миникарте/верхнему небу;
- прежние конструкторы SceneReading получают диагностическое значение 0.

Остальной полный набор повторяет 3/3, 15 секунд, один первый A, фокус, связь,
защиту, карту, CAPTCHA, смерть, обрывы, предел времени стиков, выход из лагеря,
ограниченный поиск эфира и отсутствие повторных подтверждений после неясного ввода.

SceneReading дополнен только полем water; SceneHost считает диагностическую
долю уже полученной семантики и пишет её с возрастом кадра. Current-проверка
возраста <=0.9 с, ревизии/наклона/направления не менялась. Вода не даёт отдельного
разрешения управлять. Нового алгоритма выхода на берег не добавлено.

Тесты Windows — контракт с подменённым kernel32, не доказательство реального
включённого Eco/PowerThrottling на компьютере пользователя и не измерение FPS.
Реальную скорость/поведение после оставления игры открытой нужно сверить
по новому журналу OS_BACKGROUND/SCENE_SURFACE/CONTROL_SLOW.

Архив проверяется по Python/JSON, CRC ZIP, обратному чтению каждого файла и
SHA256. Модели, зависимости, бинарные компоненты, декодер, распознавание,
Xbox-транспорт, планировщик маршрутов и код изоляции процессов сохранены.
Публикуются только полный ZIP, README_RU.md, VALIDATION_RU.md и SHA256SUMS
в downloads/gather-scanner-v0.12.20. main не меняется. Новые пользовательские
журналы, PDF, полные скриншоты и кэши не включены.

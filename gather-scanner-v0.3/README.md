# ACore2 Gather Scanner v0.3 — автосбор через Xbox A

[Скачать полную сборку ZIP](ACore2_GatherScanner_v0_3_GAMEPAD.zip?raw=true)

Сборщик на основе вашего v0.2 и исходников v26 из REFERENCE. В этой версии выбор ресурса выполняется виртуальным Xbox 360: его кнопку A вы уже проверили в игре. Физический F710 и вторая мышь не нужны.

## Как работает

1. Ищет в мире названия **Сапфир, Рубин, Алмаз, Эфир**. Орихаркон в автоматический список не входит.
2. Проверяет устойчивость найденного названия, открывает курсор через Alt и наводит его чуть ниже подписи, по прежнему алгоритму.
3. Нажимает **A два раза**, повторно выставляя курсор перед вторым A. Ждёт подтверждения нужного имени в верхнем таргете; отправку команды не считает доказательством выбора.
4. Использует игровой автоподход/автоподлёт. При появлении подсказки F или панели сбора включает **F каждые 1000 мс** через независимый Lua-таймер. Задержки OCR этот таймер не замедляют.
5. Следит за верхним таргетом и тремя полосками попыток. Краткий промах OCR не прерывает сбор. Когда таргет устойчиво пропадает, выключает F и продолжает поиск.
6. Для эфира сохраняет прежнюю логику V: при одной оставшейся попытке и полном заполнении синей/оранжевой полосы пытается немедленно сложить крылья. Резерв — исчезновение ресурса. Повторное V в одной сессии не отправляет.
7. Если названия пока нет, ищет сохранённые иконки на миникарте и отправляет два A в координаты иконки для игрового автоперехода. Во время перехода продолжает искать название в мире; найденное название имеет приоритет над миникартой. При отсутствии видимого прогресса прекращает эту попытку и временно пропускает значок.
8. Если нет ни названий, ни подходящих значков, поворачивает камеру и, при включённой соответствующей галочке, делает ограниченные шаги W. После серии шагов — пауза обзора и новый цикл. Это запасной поиск; самописного обхода препятствий здесь нет, основной подход выполняет игра.

## Установка и запуск

1. Распакуйте в **новую папку**. Не копируйте старый settings_gather.json поверх нового: в нём по умолчанию выключены ввод и автоподход.
2. ViGEmBus и Python vgamepad уже должны быть установлены после успешного теста A. Если нужен драйвер: https://github.com/nefarius/ViGEmBus/releases/tag/v1.22.0 . Архив не содержит установщик драйвера.
3. Запустите `INSTALL_ONCE.bat`. Он устанавливает зависимости Python, но не запускает установщик драйвера. Сохраняется прежнее требование Tesseract OCR с русским языком (`rus`), установленного для предыдущего сканера.
4. В отдельном профиле G HUB установите **GHUB_GATHER_SCANNER.lua из этой папки**. Именно он передаёт Alt, F, V, повороты и шаги. Боевой Lua v26 для этого протокола не подходит. Боевой сканер одновременно с новым не запускайте: у них общий канал lock-клавиш.
5. Отключите приёмник F710 и другие геймпады, как при успешном тесте. Запустите `START.bat`. Виртуальный Xbox подключается при открытии программы; результат виден в журнале. При ошибке используйте кнопку «Подключить Xbox» после исправления установки.
6. Желательно запускать игру после подключения виртуального Xbox. Если игра уже запущена и принимает его A, перезапуск не нужен.
7. В игре физически нажмите **G9 один раз**, чтобы запустить Lua-приёмник. Нужен профиль с новым Lua, а не Primary Click на G9.
8. Нажмите **Ctrl+F8** для начала. По умолчанию включены выбор двумя A, поиск по миникарте, камера и запасные шаги W. «Только наблюдение» выключено. Для первого игрового прогона можно отключить запасные шаги W, оставив выбор ресурсов и миникарту.

Физическую мышь/Alt во время автоматической работы трогать не требуется: курсор открывает Lua, его координаты выставляет Python.

## Один раз настроить миникарту

В присланных архивах нет подписанного эталона ресурсной иконки. Программа поэтому не предполагает, что любая белая точка — ресурс.

1. В игре покажите миникарту с известной вам иконкой ресурса.
2. Нажмите «Настроить миникарту / добавить иконку». Скан остановится, окно свернётся; через 4 секунды будет сделан кадр игры.
3. На кадре обведите **область самой миникарты**, без её заголовка и кнопок.
4. Щёлкните по центру значка **своего персонажа**.
5. Выберите тип иконки: конкретный ресурс или «Ресурс», если значок общий для всех материалов.
6. Плотно обведите **одну известную иконку ресурса**. Сохранение произойдёт автоматически.
7. Нажмите Ctrl+F8. Эти настройки сохраняются между запусками. После изменения масштаба интерфейса/вида миникарты настройку нужно повторить.

Тип «Ресурс» задаёт только направление поиска. Перед сбором название объекта обязательно проверяется по основному списку. Поиск названий в мире работает и без настройки миникарты.

Переход двумя A по миникарте реализован, но его действие в вашем клиенте отдельно от выбора ресурса ещё не проверено. Если нажатие на миникарту не запускает путь, в журнале будет таймаут прогресса: это не выдаётся за выполненное перемещение. В таком случае отключите поиск по миникарте для прогона мирового OCR и сохраните журнал.

## Клавиши и журнал

- **Ctrl+F8** — старт / пауза.
- **Ctrl+F9** — остановка программы; ожидающее/второе A отменяется, виртуальный геймпад сбрасывается.
- **Ctrl+F10** — заглушить текущую звуковую тревогу.
- Кнопки «Скопировать журнал» / «Сохранить журнал...» позволяют передать результат проверки.
- Полный журнал автоматически пишется в `gather.log` рядом с программой.

Остановка программы прекращает её ввод; уже запущенный собственный автопуть игры при необходимости отменяется штатным управлением. F/Alt/V освобождаются Lua-командой STOP; Lua также имеет независимый watchdog 6500 мс на случай исчезновения команд Python.

Детекторы CAPTCHA/смерти и четыре картинки сохранены побайтово из REFERENCE/v26. Они работают при запущенном скане во время поиска, перехода и сбора. Обнаружение останавливает ввод и включает соответствующий звук на настроенном выходе AG271QG4. После тревоги требуется ручное продолжение. CAPTCHA не решается автоматически.

## Что проверено

- Исходный офлайн-тест: OCR названия/дистанции на кадрах, подсказка F, панель сбора, 1–3 полоски, отрицательные кадры CAPTCHA/смерти, кодирование команд Lua.
- Интеграционные тесты: ровно два A по прежним координатам, отмена между A, отпускание A/Alt при ошибке, режим наблюдения, подтверждение таргета перед F, окончание сбора при исчезновении таргета, устойчивость к одиночному промаху OCR, смена цели, переход по координатам миникарты и выход из застревания.
- Детектор иконок проверен на контролируемой картинке с сохранённым шаблоном и на пустом отрицательном кадре. Настоящие иконки нужно сохранить из вашей игры описанной настройкой.

Полный живой цикл новой версии ещё не проверен: в среде разработки нет вашей игры и Windows-драйвера. Из игровой проверки подтверждено ваше программное A; остальная цепочка собрана для следующего прогона.

Старые описания сохранены в `docs/history/`; они относятся к предыдущим версиям.

# Проверки v0.12.21 QWEN

Полный набор: 1778 tests, OK, без пропусков.
44 новых проверки в test_qwen_experiment.py; остальной набор v0.12.20 сохранён.

Проверено офлайн:

- Настоящий локальный HTTP-сервер получает два JPEG вида мира и отдельную
  миникарту, структурированный ответ собирается из потока NDJSON.
- think=false, контекст 4096, максимум ответа 256, keep_alive=30s; модель
  qwen3-vl:8b-instruct-q4_K_M. Официальный тег проверен в каталоге Ollama.
- Команды вместо схемы, NaN/Inf, bool вместо числа, недопустимые значения,
  пустой content и обрезанная схема не превращаются в действия.
- Ограничение локального адреса без redirect/proxy остаётся.
- Асинхронный занятый/сломанный запрос не блокирует поток управления,
  не создаёт очередь потоков. Ошибка даёт паузу повторных запросов.
- Поздний ответ не объявляется готовым ИИ; после трёх поздних ответов
  вызывается выгрузка и 60 с перерыва. Закрытие во время запроса запрещает
  публикацию результата и запрашивает выгрузку после завершения.
- Направление старого кадра переносится на другой ID текущего связного
  прохода при небольшом повороте, а не кликает в старые пиксели.
- Новая цель того же типа/новая попытка выхода из лагеря, большой поворот,
  наклон, сдвиг, изменение направления ресурса, отсутствие текущего прохода,
  край и неудачный курс отвергают совет. Низкая уверенность не даёт обход.
- Максимум 3 с применения. Неуспешный обход даёт no_progress; неизвестное
  смещение не выдаётся за подтверждённое застревание. Результат движения не
  выдаётся за сбор ресурса. Память ограничена двумя видами/12 результатами.
- Нет ложного применения, если локальный планировщик выбрал другой маршрут.
- Настоящий HybridGatherEngine выдаёт боковое движение по подходящему совету;
  ошибка/занятая модель не отключают нормальное движение по миникарте.
- Стабилизация камеры у лагеря не препятствует передаче кадров помощнику.
- Подтверждённый собственный удар запускает DEFENSE без нового кадра даже
  при занятой модели; подтверждённый сбор обходит эксперимент.
- Из сети передаются только подтверждённые собственные факты, без actor ID.
- Пользовательская проверка выгружает модель и после ошибки. Установщик
  скачивает точный тег и включает эксперимент только после подходящего
  прогретого ответа и подтверждения GPU-загрузки выбранной модели.

Это контракты API, ограничения, сценарии отказов и работа обработчика управления
с заданными ответами. В этой среде НЕТ NVIDIA, Ollama и запущенного AION2.
Настоящий ответ Qwen8B, точность понимания игровых сцен, задержки на RTX4080Super,
расход VRAM с игрой, влияние на FPS и улучшение проходимости здесь НЕ измерены.
SETUP_ANALYZER.bat выполнит настоящие запросы на ПК пользователя и сохранит
qwen_experiment_check.json. Его синтетические изображения проверяют работоспособность
API, не качество игровой навигации. Для качества нужны игровые запуски.

База — полный v0.12.20 FLOW. Код gathering state machine, сбор/15с/3попытки,
сетевой декодер, защита, распознавание эфира, навигатор миникарты, карта возврата,
контроллер Xbox, ограничение стиков и локальные модели/зависимости сохранены.
В HybridGatherEngine добавлен выбор нового помощника, передача контекста и
учёт принятого обхода. Ветка без включённого анализатора сохраняет локальное
управление. Прежний RouteAdvisor остаётся для совместимости с настройками
qwen_temporal_enabled=false; новые настройки используют TemporalAdvisor.

allowlist файлов из предыдущего ZIP + новые исходники/скрипты/история,

main, новые пользовательские журналы, скриншоты, PDF, настройки сеансов,

# Проверка отдельной AI Pilot v0.1.0

Полный прогон: 1159 тестов, OK, без пропусков. Сохранены 1140 проверок
классических компонентов плюс 19 новых сценариев AI-политики и инструментов.
Lua выполнен через lupa, OFFLINE TESTS PASS. Проверки в Linux, без живых
AION2/Windows/RTX 4080/Qwen. Это не измерение качества игрового поведения.

Новые сценарии проверяют границы длительности/координат, запрет произвольных
команд, две картинки и историю в запросе, отмену запоздалого ответа при смене
поколения задачи, поток /api/generate с фрагментами и финальным done=true,
отсутствие старого Navigator во время ожидания, однократную ограниченную команду
движения, отзыв клика по изменившемуся виду, приоритет существующего сбора,
запрет взлёта с неизвестной энергией, стоп, один нативный клик LB+LT+A,
неподтверждённый объект без второго A, передачу подтверждённого ID контроллеру
APPROACH, запрет ввода при отказе сети, отключение автоматических старых
спасения/патруля/возврата, наблюдение без ввода и перенос выбранной цели
в следующий запрос модели.

Установка и CHECK_AI на Windows требуют проверки пользователя. Контракт API
проверен настоящим локальным HTTP-сервером, а не самой нейросетью. Тестовая
готовность не доказывает распознавание стены, выбор обхода или попадание по
маленькому ресурсу. Два кадра и история могут увеличить задержку/память.

Tk-окно открыто: отдельный заголовок, выбор 3B/7B, настройки и журнал видны;
подключение геймпада отключено для этой проверки. Игрового ввода не было.
После заключительной правки обратной связи инструментов повторены 19 AI-тестов.

Настройки автоматического спасения в этой отдельной ветке намеренно false;
соответствующая проверка конфигурации изменена, проверки классического
контроллера с его прежними параметрами сохранены. Новая ветка не редактирует
источник/архив GatherScanner v0.11.3. Совпадение старого архива с опубликованным
SHA проверяется при упаковке новой версии.

Lua, сетевой EXE, модели и лицензии побайтно сохранены. Архив составлен по
явному списку; новые личные журналы, ai_check.json, полные снимки, сетевые
захваты, кэши, venv и результаты частной проверки не публикуются.

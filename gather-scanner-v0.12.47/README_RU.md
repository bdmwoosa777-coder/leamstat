# v0.12.47 WIRE — исправление канала автопути

Патч поверх ПОЛНОЙ v0.12.45, в том числе уже обновлённой до v0.12.46.
Содержит предыдущее исправление проекции ресурса без обязательной стрелки.

## Установка — Python и Lua обновляются вместе

1. Остановите и закройте бот. Распакуйте ZIP в его папку с START.bat, с заменой
   файлов. В заголовке после запуска должно быть v0.12.47.
2. В G HUB замените содержимое активного скрипта на НОВЫЙ GHUB_MAP_MOUSEKEYS.lua
   из этого патча. Save & Run завершает прежний приёмник; затем нажмите G9.
   Должна появиться строка `[MAP V2] G9 ARMED; Num Lock never pressed`.
   Файлы HISTORY являются историей: НЕ запускайте их как приёмник.
3. Windows Mouse Keys оставьте включёнными. Num Lock включите вручную и больше
   не переключайте во время работы. Новый бот сам эту клавишу не нажимает.
4. Если персонаж ещё бежит от предыдущей версии, вручную остановите движение.
   Нажмите «Проверить новый Lua», затем запустите бот. Старый Lua не проходит
   проверку нового канала: PING должен подтвердить именно Lua v2.

Lua обязательно обновить: этот протокол несовместим с прошлым. Г9 остаётся
кнопкой включения приёмника. Рабочий сбор и бой обслуживает прежний Xbox.
Настройки/1200 мс камеры, галочки, сетевой захват, модели, атлас не входят в патч
и сохраняются. Никакой новой калибровки карты не требуется.

Для установки с нуля сначала нужна полная v0.12.45:
https://raw.githubusercontent.com/bdmwoosa777-coder/leamstat/38b621557164e7d3808b573dd7e07fd7c4bcc232/gather-scanner-v0.12.45/ACore2_GatherScanner_v0_12_45_AUTOPATH.zip

## Что было обнаружено

В новом журнале уже есть перевод курсора и MAP_PATH_CLICK, ACK Lua подтверждён,
но надпись игрового автопути не появляется. ACK означает отправку клавиш Lua,
а не принятие ПКМ игрой. Длительного ввода вперёд стиком в журнале нет;
есть короткий обратный импульс при отмене неудачи и остановке.

Прежний Python → Lua использовал Caps/Num как два бита, Scroll как такт.
Включённый Windows Mouse Keys не мешал передатчику многократно нажимать
Num Lock для каждого PING/M/ПКМ. В игре эта клавиша может отвечать за автобег:
такая привязка превращает служебную передачу в движение и отмену маршрута.
Привязка на конкретном ПК журналом не устанавливается. Удалена сама причина
ненужных нажатий Num Lock, независимо от привязки.

Новый отдельный канал использует Caps как один бит и Scroll как такт.
Num Lock постоянно включён. Прежний общий Lua-канал не переписан; для игрового
автопути используется только новый. После ACK выдерживается 90 мс, чтобы Lua
отпустила клавишу подтверждения и успела вернуться к приёму следующего кадра.

После неудачного клика БЕЗ игрового подтверждения больше нет толчка стиком.
Подтверждённый застрявший маршрут, явная отмена и Ctrl+F9 по-прежнему могут
кратко остановить движение. Во время подтверждённого автопути патруль, спринт,
DirectML и реакции на обычные удары мобов не получают управление.

## Галочки

Оставьте набор с последнего скрина: основной автопуть, дальний полёт, сеть,
выбор/продолжение сбора, приоритет эфира, миникарта, осмотр, защита,
автокалибровка включены. DirectML, Qwen, патруль, спринт и старый выход назад
выключены. Кнопка «Галочки для автопути» применяет этот набор.

## Что должно быть видно

После карты — курсор в точку ресурса, `[MAP V2] numminus + num5 DOWN/UP` в G HUB,
MAP_PATH_CLICK с пикселем в журнале бота. Затем карта закрывается и появляется
игровая надпись «Автоперемещение(N м)». Только она подтверждает маршрут.
Если её нет, бот сообщает это, не приписывая Lua ACK успешный автопуть.

Испытаны настоящий Python-передатчик вместе с настоящим Lua через виртуальную
клавиатуру и имитацию игры с Num Lock = автобег, а также остальной бот.
Windows/G HUB/AION2 в этой среде нет; успех на реальном ПК не заявляется.

# ACore2 GatherScanner v0.7 NETWORK

Экспериментальная сборка для AION2 Global EU/NA. Сеть теперь участвует в управлении сбором и защите, а не только записывает диагностику. Live-проверки этой сборки в игре здесь не было.

## Запуск — 4 шага

1. Закрой предыдущего бота. Распакуй **v0.7 в новую папку**. Можно перенести settings_gather.json и свою папку assets/world_map. Python, Tesseract и виртуальный Xbox остаются прежними.
2. Открой G HUB, верни **ON-BOARD MEMORY MODE → OFF**, включи игровой профиль с прежним Lua и физически нажми G9 для запуска приёмника. **Lua менять не нужно.** Встроенная память мыши не исполняет этот Lua-приёмник.
3. Запусти `START.bat`. Нажми **«Выбрать Cube.Radar.exe»** и укажи тот файл CubeRadar, которым делал запись. Путь сохранится. Отдельно запускать запись, закрывать её через 3 минуты и ставить отметки не требуется. Если файла нет: [загрузка CubeRadar](https://github.com/dr89mh/aion2-cube-radar/releases/latest). Npcap уже должен быть установлен.
4. Оставь галку **«Проверять сбор и удары по данным игры»**, нажми **Ctrl+F8** и переключись в игру. Дождись данных персонажа. Если программа просит — один раз сделай рывок вручную: собственные показатели помогут определить персонажа. **Ctrl+F9 — стоп**.

AionCore не используется как источник данных этого подключения. Он может продолжать работать своим захватом; совместный живой запуск на твоём ПК ещё предстоит проверить.

## Что проверяется по сети

- Выбор A должен получить свежее подтверждение цели. После него отправляется один стартовый F. Повтор F разрешается по связанным сообщениям **собственного** начала сбора, а не по случайно похожей картинке. Если сбор уже начался во время выбора/подхвата, новый стартовый F не отправляется.
- Нулевой выбор между обычными попытками сохраняет ресурс. Крылья не закрываются из-за одного такого события. Счётчик 1/2/3 использованных попыток и удаление узла сервером завершают сбор; выход из видимости учитывается отдельно.
- Другой игрок рядом не разрешает наш повтор F. Новая выбранная цель отзывает прежнее разрешение.
- Числовая энергия крыльев и её явно полученный максимум уточняют бюджет. Неизвестный максимум остаётся неизвестным; в этом случае сохраняется прежнее измерение по экрану. Нулевую полученную энергию не подменяет оценка восстановления.
- Tab запускает подтверждённое сетевое **попадание по нашему персонажу**. Урон от падения, полное/изменившееся изображение HP и красные точки не запускают эту защиту. Атакуется именно ID ударившего моба после двух проверок выбора. Моб может держать в цели духа — совпадение правой плашки с Darkleam больше не обязательно.
- Смена цели проверяется после каждого Tab; максимум три попытки на проверку. Неподтверждённый NPC или чужая выбранная цель не атакуются. После подтверждённой смерти сохраняются прежние возврат к ресурсу и новый одиночный стартовый F.

## Если данные задержались

Пакеты проверяются по времени захвата. При задержке более 2.5 с программа прекращает повтор F и собственные движения, сохраняя текущий ресурс. Уже запущенный самой игрой автопуть при этом может продолжаться. При ошибке источника/длительном отсутствии подтверждения ввод останавливается с объяснением в журнале. Автоматического перехода к старой HP-защите нет.

Захват запускается и закрывается вместе с рабочим циклом. В папке **network_captures** остаётся локальная запись; она может содержать личные данные. Она никуда автоматически не отправляется. Обычный журнал — **gather.log**, кнопка «Папка журнала» открывает его папку. Если возник сбой, первым нужен этот журнал, а не новая запись вручную.

## Что ещё остаётся ограниченным

- Поиск подписей/иконок и наведение курсора пока работают по изображению. Координаты ресурсов уже декодируются, но карта покрытия местности и маршруты по XYZ ещё не подключены.
- Путь к ресурсу по-прежнему выполняет игра через A/F. Сеть не даёт готовой сетки проходимости и сама не решает обход любой скалы.
- Защита сейчас использует поддержанный прямой Hit (04 38). Отдельный DoT ещё не запускает её. Определение нападения на одного духа без попадания по персонажу не добавлено.
- Если профиль моба появился до запуска захвата, его тип может быть неизвестен. Такой ID не получает разрешение на атаку. Это ограничение нужно проверять при тесте в игре.
- Начальная идентичность определяется собственным профилем или повторяющимися личными показателями полёта/энергии Global. При противоречии/смене персонажа управление блокируется; жёстко заданного ID персонажа нет.
- До первого подтверждённого сбора сохраняется штатное восстановление у препятствия: допустимый V и один F после подтверждения открытых крыльев. Самопроизвольный повтор стартового F по таймеру не добавлен. Если за 60 с сбор не начался, сетевой режим останавливается с сохранением цели.
- Отключение сетевой галки возвращает визуальный режим предыдущей версии. Новые сетевые проверки в нём не действуют.

Проверки и ограничения — в VALIDATION_RU.md. Исходные данные пользователя в архив не включены. Происхождение сетевых схем и лицензии — THIRD_PARTY_NETWORK.md.

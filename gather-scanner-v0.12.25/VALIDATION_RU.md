# Проверки v0.12.25 BOOT

Полный набор: 1884 tests, OK, без пропусков.
17 новых сценариев test_boot_background.py.

Последний пользовательский журнал v0.12.24: QWEN_PRELOAD, ожидание загрузки
90.047 с, timed out, отменённый старт. Нет запуска управления, QWEN_RESULT
или QWEN_APPLY. Пользователь подтвердил размещение моделей на обычном HDD H:.
HDD — правдоподобный источник долгой загрузки, но однозначная причина
тайм-аута по этому журналу не установлена. Замеров после переноса на SSD нет.

Проверено фактическое выполнение обработчиков UI с настоящим TemporalAdvisor
и намеренно заблокированным warmup в управляемом клиенте. Рабочий обработчик
_go запускает подставной движок, пока загрузка ещё висит. Затем клиент выдаёт
timed out: помощник приостановлен, stop движка не вызван, событие остановки
не выставлено. Контролируемое сравнение обработчиков v0.12.24/v0.12.25 также
показывает отсутствие/наличие запуска контроллера при той же ошибке загрузки.
Это проверка порядка выполнения, без реального геймпада и игры.

Новые сценарии проверяют:

- фоновый режим в DEFAULT и поставляемом settings_gather.json;
- запуск контроллера во время зависшей загрузки и продолжение после ошибки;
- ожидание предыдущей выгрузки только помощником, без задержки контроллера;
- сохранение первой незавершённой загрузки при нескольких быстрых перезапусках;
- запрет фоновых callbacks после остановки, закрытия, смены токена или движка;
- ожидание завершения прежнего контроллера до создания нового движка;
- различие статусов «подготовлен» / «игровой ответ» / «приостановлен»;
- отсутствие автоматических повторных загрузок после неудачной подготовки;
- отмену во время загрузки без публикации совета и с последующей выгрузкой;
- настоящий локальный HTTP: один model, num_ctx=4096 и keep_alive=10m у
  загрузки/анализа; выгрузка keep_alive=0 и проверка ответа done=true;
- read-only вызов nvidia-smi с ограниченным тайм-аутом, правильные единицы MiB,
  обработку отсутствующего инструмента и зависшего процесса;
- путь из окружения без ложного утверждения о настройке уже запущенного сервера;
- ограниченный отчёт фазы ошибки, VRAM, версии и контекста без картинок/промпта.

Прежняя группа проверок обязательного ожидания Qwen сохранена для явного
qwen_wait_before_start=true. В её fixture добавлен этот флаг, поскольку
обязательное ожидание больше не является поведением по умолчанию.

Сами веса, зависимости, модели сцены, сетевой декодер, навигатор миникарты,
распознавание/выбор ресурсов, карта, Xbox-транспорт и калибровка не менялись.
В hybrid_engine.py изменён только номер версии. Приоритет подхода/сбора
над общим возвратом из v0.12.24 и ограничения свежести/обрывов сохранены.

Реальный тайм-аут на HDD, размещение весов в VRAM, ускорение SSD, конкуренция
с AION2 и качество игровых обходов здесь НЕ измерены. HTTP и GPU-диагностика
проверены протокольными/подставными ответами; работа на RTX4080Super требует
испытания на пользовательском ПК. Загрузка и анализ теперь используют один
контекст, но это не доказательство причины прежних 90 секунд.

Пакет собирается по allowlist из прежнего опубликованного ZIP и явно добавленных
файлов. Проверяются Python/JSON, дубликаты методов, неизменность весов/бинарников,
CRC ZIP, побайтовое обратное чтение и SHA256. В downloads-ветку публикуются
только полный ZIP, README_RU.md, VALIDATION_RU.md и SHA256SUMS. main, новый
журнал пользователя, runtime-отчёты, новые кадры и кэши в публикацию не входят.

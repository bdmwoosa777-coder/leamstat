# GatherScanner v0.12.46 TARGET — обновление для v0.12.45

Исправлена причина отсутствия движения курсора из пользовательского журнала:
рельеф M успешно распознавался, но нераспознанная стрелка персонажа запрещала
переход к выбору точки. В итоге повторялись открытия/закрытия M без ПКМ.

Теперь подтверждённое преобразование рельефа пригодно для перевода XYZ ресурса
в пиксель карты независимо от стрелки. Неизвестная собственная позиция не
подменяется выдуманной координатой и не запрещает клик по известной цели.

## Установка

Это небольшой патч ТОЛЬКО поверх полной v0.12.45 AUTOPATH. Закройте бот,
распакуйте содержимое ZIP прямо в папку v0.12.45, где находится START.bat,
с заменой файлов. Затем запустите START.bat. В заголовке будет v0.12.46.

Пользовательский settings_gather.json не входит в патч: галочки, радиус и
1200 мс камеры сохраняются. Встроенный атлас и полный каталог берутся из
уже установленной v0.12.45. Для новой установки сначала нужна полная v0.12.45:
https://raw.githubusercontent.com/bdmwoosa777-coder/leamstat/38b621557164e7d3808b573dd7e07fd7c4bcc232/gather-scanner-v0.12.45/ACore2_GatherScanner_v0_12_45_AUTOPATH.zip

Рабочий GHUB_MAP_MOUSEKEYS.lua из G9-патча оставьте включённым. В данном
журнале после 12:48 его ACK уже был подтверждён: переустановка Lua ради этой
ошибки не нужна. Если G HUB перезапускали: Save & Run, затем G9. Windows
Mouse Keys и Num Lock остаются включёнными.

## Что изменилось

- Рельеф подтверждён + есть доступный ресурс с сетевыми XYZ: вычисляется точка,
  курсор переводится к ней, отправляется один числовой ПКМ, M закрывается.
- Если живых целей пока нет, используется каталог в видимой области карты.
  Для выбора области предпочтительны свежая собственная позиция, затем
  расположение видимых сетевых ресурсов, затем середина видимой области M.
  Два последних варианта обозначают область поиска, а не измеренное положение
  персонажа. Радиус поиска остаётся установленным пользователем.
- Старое собственное XYZ старше 0,8 с или без подтверждённого своего ID не
  выдаётся за текущее. При отсутствии стрелки это не мешает работе по цели.
- Метры берутся из игрового «Автоперемещение». Если прямое расстояние до цели
  неизвестно, дальний путь может один раз переводиться в полёт по измеренной
  игрой длине от 80 м, при включённой опции и известной энергии от 50%.
- Исчезновение надписи после подтверждённого автопути передаёт управление
  визуальному поиску; без своей позиции точное прибытие по XY не заявляется.
- Неудачный необязательный поиск стрелки повторяется реже. Повторные секунды
  вычислений ради одной и той же отсутствующей стрелки не блокируют ПКМ.

Проверки рельефа, карты, текущей точки, курсора, фокуса, окна и своего сбора
перед кликом сохраняются. Неподтверждённое изображение карты не даёт разрешения
кликать. Старый патруль и спринт остаются выключенными; сбор всех попыток,
защита и статистика не переписывались.

## Галочки

Сохраняйте набор v0.12.45: основной автопуть, сеть, выбор/продолжение сбора,
приоритет эфира, иконки, осмотр камеры, защита и автокалибровка включены.
DirectML, Qwen, патруль стиком, спринт A и старый выход назад выключены.
При необходимости кнопка «Галочки для автопути» применяет этот набор.

## Проверка в игре

Теперь после MAP_FIX допустима запись «позиция персонажа неизвестна; цель
вычисляется по рельефу». Затем должны быть MAP_MOUSEKEYS / MAP_PATH_CLICK с
названием цели и видимое перемещение курсора к вычисленной точке. Сам ACK Lua
не означает, что игра построила путь: это проверяется отдельно надписью автопути.

В этой среде нет живой Windows/G HUB/AION2. Проверены действительные SIFT-привязка
рельефа, проекция ресурса и переход контроллера до курсора/одного ПКМ при
принудительно нераспознанной стрелке. Это не заменяет живую проверку на ПК.
Пользовательские журналы, кадры и настройки не включены в обновление.

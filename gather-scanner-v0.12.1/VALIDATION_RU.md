# Проверка GatherScanner v0.12.1

Полный заключительный прогон: 1244 tests, OK, без пропусков.
Lua command protocol: 16 commands OK; Resource UI and negative CAPTCHA/death:
PASS; OFFLINE TESTS PASS. Новые сценарии: test_smooth.py и test_xbox_bridge.py.

Среда: Linux, Python 3.12, OpenCV, Tesseract eng/rus, Lua через lupa,
синтетические пакеты/картинки, тестовый HTTP-сервер и тестовый Xbox pad.
Исторические проверки v0.12.0 — HISTORY_v0_12_0_VALIDATION_RU.md.

Проверено для обновления:

- движение сохраняется между обновлениями каждые 0,5 с, хотя камера и её
  горизонтальный импульс заканчиваются раньше; при прекращении обновлений
  сбрасываются оба стика;
- явный ноль/reset, отказ разрешения движения/камеры и вход в LB+LT немедленно
  снимают продлённый ход; настройка не продлевает его выше ограничения транспорта;
- свежая подпись останавливает движение до следующего шага навигации;
  уже рассчитанный новый поворот не может сразу возобновить обзор;
- свежий эфир на фоне неба имеет приоритет перед коррекцией наземного
  ракурса и отложенной калибровкой; сама заявка калибровки сохраняется;
- старый кадр, начатый сбор, выход из области кибелиска не создают захват подписи;
  отсутствие актуального глифа не разрешает A; ожидание имеет конечный срок;
- настоящий изолированный образец подписи/ромбика эфира из прежней тестовой базы
  заново находится на текущем кадре и передаётся штатному ACQUIRE_WAIT;
  следующий выбор получает свежий ромбик;
- возврат к ракурсу распознавания имеет короткий срок, который не продлевается
  от сглаживания ходьбы; выбор ресурса снимает захват подписи без лишнего A;
- замеченный эфир в спасательном перелёте прекращает только манёвр,
  без END_AIR и без предположения о посадке;
- после подъёма выполняется верхний упор, затем заданное опускание;
  новый цикл сбрасывает прежнюю точку упора, неподвижная камера заканчивает
  восстановление явной ошибкой за ограниченное время;
- изменение направления на иконку во время перелёта не меняет исходный курс;
  сам перелёт по-прежнему ограничен четырьмя секундами;
- ConnectionRefused отличается от таймаута и ошибки JSON модели; запуск
  установленного ollama serve ограничен по частоте, не скачивает модель,
  не повторяется для живого дочернего процесса и не вызывает установщик.

Старые ожидания широкого поиска намеренно изменены: прежние импульсы 270 мс
заменены на 60 мс. Проверяются суммарный симметричный ход, границы начального
подъёма, паузы и сохранение последовательности при задержках кадров.
Проверки спасения учитывают дополнительный верхний упор; конечный бюджет
AreaRecovery допускает завершающий ограниченный возврат камеры после 45 с.
Этот необязательный режим по умолчанию выключен: area_search_rescue=false.

Нативный транспорт дополнительно проверяет:

- соответствие RS/Y/X/Start/LS подтверждённым маскам Xbox, без LB/LT;
- две атаки RB и отзыв разрешения перед второй; RT/AOE не представлены;
- LB+LT для каждого A в игровом мире; голая A и универсальная передача A запрещены;
- B в мире и неподготовленном меню запрещена; подтверждение карты требует
  разрешения, текущего меню и предварительной подготовки UI;
- прокрутка списка передаёт LT и вертикальную ось правого стика без LB/A;
  стоп, потеря фокуса и отказ проверки снимают ввод;
- отдельный срок удержания обычной кнопки нельзя продлить обновлением движения;
- закрытие диалога вследствие разрешённой B/A не объявляется ошибкой отправки:
  свежесть окна проверяется перед нажатием, удержание защищено стопом/фокусом,
  результат затем проверяется следующим кадром;
- стандартный HybridGatherEngine создаётся при запрете конструктора GHubBridge;
  предпусковая проверка отправляет только LB+LT без A и игровых действий;
- разрешение курсорной A использует состояние LB+LT; вход в управление камерой
  освобождает курсор без клавиатурных команд.

Игровой запуск не выполнялся. Windows/G HUB/Npcap, реальный запуск процесса
Ollama, реальная Qwen, GPU и FPS вместе с AION2 здесь не проверены.
Запуск Ollama проверен с подменённым процессом; узнавание образца — локально,
без воспроизведения движения реальной камеры. Офлайн-успех не доказывает
улучшение количества добытых ресурсов, отсутствие всех застреваний или
точность оценки реальных обрывов. Новые полные кадры пользователя в тесты
и в архив не включены.

Публикуются ZIP, README, VALIDATION и SHA256SUMS. Личные журналы, новые
полные снимки и сетевые захваты исключены. Резервный Lua-файл, сетевой EXE, ONNX и требования
к библиотекам сверяются с опубликованной v0.12.0 побайтно.

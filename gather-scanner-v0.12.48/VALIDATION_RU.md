# Проверка v0.12.48 QUIET

160 целевых регрессионных тестов, OK, без пропусков, 12.999 с.
Выполнены test_quiet48, test_map_wire47, test_map_mousekeys44,
test_map_autopath44, test_map_target46, test_autopath45,
test_map_coordinates44 и test_map_registration44.

8 новых проверок соединяют настоящий MapAutopath, настоящий MapMouseKeys/
MapKeyWire и настоящий Lua на виртуальном Windows вводе. PlayMacro и игра
имитируются. Проверено: карту нельзя закрыть до отложенного SDK-клика;
маршрут и вопрос о полёте могут менять изображение без отмены принятой
команды; потеря фокуса, движение курсора/окна и Stop до макроса его отменяют;
перезапуск Python с тем же Lua-приёмником не теряет синхронизацию.
Остальные проверки покрывают карту/каталог/живые XYZ, слепые/ложные клики,
двухсекундную тишину, отсутствие Num Lock, запрет повторов при потере ACK.

В успешном пользовательском QUIET-тесте Windows зарегистрировала правый
DOWN/UP после двухсекундной паузы, пользователь подтвердил работу в игре.
Перенесена та же последовательность. Результат в живой игре после интеграции
в рабочий бот здесь ещё не проверен: Windows/G HUB/AION2 отсутствуют.
ACK трактуется только как приём; факт пути проверяет отдельный HUD-контроллер.

Проверяются канонические исходники v0.12.45 + v0.12.47 по SHA-256,
явный состав изменений, неизменность настроек/моделей/атласа/сети/сбора,
синтаксис Python/JSON, уникальность Windows путей без учёта регистра,
отсутствие unit-тестов в ZIP, CRC/байты/SHA-256. Архив содержит только
пять рабочих Python/Lua файлов и инструкции. Пользовательские данные
не публикуются. Lupa нужна лишь среде разработки, не пользователю бота.

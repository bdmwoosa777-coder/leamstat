# Проверка MAP CLICK TEST 2

43 целевых теста, OK, без пропусков, 0.058 с.

Сохранены прежние проверки одиночной передачи Python → реальный Lua через
виртуальную клавиатуру, отказа без ACK/разрешения, отсутствия повторов,
неизменности Num Lock, разбора правых/левых DOWN/UP, Num5/Clear и цифровых
скан-кодов, исключения обычного буквенного ввода из журнала.

Четыре новые проверки: фокус/границы окна/курсор; отказ вне клиентской области;
корректные отрицательные координаты дополнительного монитора; действительный
main с заглушкой экрана, которая падает при попытке чтения изображения.
Последний тест проходит до одного клика и сохранения лога без вызова frame/OCR,
воспроизводя устранённую блокировку предыдущего диагностического инструмента.
Привязка карты и распознавание текста не являются условием этой ручной проверки.

Источник проблем в рабочем автоматическом клике пока не установлен.
Последний пользовательский журнал не содержал ни PING, ни команды клика:
прежний тест вышел на проверке карты. Его нельзя засчитывать как результат
ПКМ. В этом обновлении меняется только отдельный тест, не рабочий бот/Lua.
Windows hooks и принятие ПКМ игрой в данной среде не проверяются: Windows,
G HUB и AION2 отсутствуют. Пользовательские файлы в ZIP не включены.
Проверены синтаксис Python, состав, байты, CRC и SHA-256 архива.

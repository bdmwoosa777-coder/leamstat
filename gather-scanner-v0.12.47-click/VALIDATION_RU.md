# Проверка Lua CLICK v0.12.47.1

85 целевых тестов, OK, без пропусков, 4.299 с.

Проверены настоящий Python v0.12.47 MapKeyWire/MapMouseKeys вместе с новым
Lua через Lupa и виртуальную клавиатуру; Num Lock не нажимается,
PING → M → один числовой ПКМ → M проходит, клавиши отпускаются.
Проверены отзыв разрешения, отсутствие/несовместимость ACK, серия команд,
контроллер автопути, проекция живого ресурса и каталога без стрелки.

Два новых регрессионных теста проверяют вызов PressAndReleaseKey для обеих
цифровых клавиш и интервал 100 мс между ними. Тестовая имитация API различает
PressKey/ReleaseKey и PressAndReleaseKey; атомарный вызов не сводится к
заранее успешному ACK. Тестовые адаптеры поддерживают новый API G HUB.

Windows/G HUB/AION2 в среде отсутствуют. Пользователь подтвердил рабочий
отдельный G9-тест с PressAndReleaseKey. Действительный автоматический канал
Python → G HUB → игра после этого изменения ещё требует проверки на его ПК.
Прежний тест не доказывает, что именно разница API была единственной причиной
неуспеха v0.12.47. Вариант с проверенным API перенесён без изменений Python.

Единственный изменённый рабочий файл — GHUB_MAP_MOUSEKEYS.lua.
В ZIP также входят тесты, история двух прежних Lua и инструкции.
Архив и все включённые файлы проверяются по CRC, байтам и SHA-256.
Пользовательские логи, кадры и настройки не включены.

# Lua CLICK v0.12.47.1 — только для Python v0.12.47

Отдельный физический G9 запускал функцию Lua, а Num− и Num5 генерировал
сам скрипт через PressAndReleaseKey. Пользователь подтвердил в игре,
что эта последовательность запускает автопуть. Это проверка программной
отправки клавиш G HUB; весь Python → Lua → игра этим тестом не проверялся.

В автоматический приёмник перенесены те же API и порядок:
PressAndReleaseKey("numminus"), Sleep(100), PressAndReleaseKey("num5").
Прежние PressKey/Sleep(50)/ReleaseKey для цифровых клавиш удалены.
Вызовы M, F и подтверждения, протокол v2, управление Python не меняются.

## Установка

1. Остановите бот. Распакуйте ZIP в папку установленной v0.12.47 с заменой.
   Python, карта и settings_gather.json в патч не входят и не меняются.
2. Вместо временного короткого теста вставьте в активный Lua G HUB полное
   содержимое GHUB_MAP_MOUSEKEYS.lua ИЗ ЭТОГО ОБНОВЛЕНИЯ. Нажмите Save & Run,
   затем G9. В журнале G HUB появится `[MAP CLICK 47.1] G9 ARMED`.
   HISTORY — файлы истории: их не надо включать как активный скрипт.
3. Запустите прежний Python v0.12.47, проверьте Lua и запустите сбор.

Num Lock НЕ НАЖИМАТЬ. Уже рабочее состояние Windows Mouse Keys оставьте
как есть. Ни Python v0.12.47, ни этот Lua не переключают Num Lock.
Галочки, 1200 мс камеры и прочие настройки остаются прежними.

G9 в полном приёмнике включает прослушивание один раз. После этого
цифровой ПКМ должен вызываться командой Python, а не повторным ручным G9.
Новый журнал Lua при таком вызове: `[MAP CLICK 47.1] PressAndReleaseKey ...`.
ACK всё ещё означает исполнение Lua. Надпись игры «Автоперемещение»
отдельно подтверждает путь. Живой автоматический запуск этой версии
пока не проверен; подтверждён пользователем только отдельный G9-тест.

Если установлен более старый Python, сначала нужна полная v0.12.45
и патч v0.12.47. Этот маленький ZIP сам по себе ботом не является.

# ACore2 Gather Scanner v0.4.2 — штатный автопуть и обход V → F

Исправление v0.4 по новым скриншотам и уточнённой механике: выбранный ресурс запускает автоподход по F. Выбор ресурса по-прежнему выполняется виртуальной кнопкой Xbox A; физический F710 не нужен. Движение и камера теперь также управляются стиками виртуального Xbox.

## Запуск

1. Распакуйте в **отдельную новую папку**, выполните `INSTALL_ONCE.bat`. ViGEmBus уже должен быть установлен после рабочего теста A; его установщик скрипт не запускает. Tesseract OCR с языком `rus` нужен как раньше.
2. **При переходе с v0.3 замените Lua на GHUB_GATHER_SCANNER.lua из этого архива**. Lua совместим с v0.4; если v0.4 уже установлен, его менять не требуется. Боевой сканер одновременно не запускайте: канал lock-клавиш общий.
3. Отключите приёмник F710 и другие геймпады. Запустите `START.bat`, дождитесь строки «Виртуальный Xbox подключён».
4. В игре физически нажмите G9 один раз для Lua. Затем Ctrl+F8.
5. По умолчанию включены автоматическое движение, поворот камеры, миникарта и выбор ресурсов. «Только наблюдение» выключено.

Старый settings_gather.json не переносите поверх нового. В v0.4 уже заданы настройки патруля; пустая область миникарты теперь означает автоматическую область, а не отключение поиска.

## Что изменилось

- Вместо долгих пауз между четырьмя короткими поворотами и одним W идёт обновляемое управление стиками. Камера поворачивается к иконке, движение начинается при совпадении направления.
- Направление камеры определяется по **двум границам конуса обзора** на верхней миникарте, не по стрелке персонажа. Теперь учитываются полупрозрачные границы и светлая внутренняя часть сектора: яркая дорога сама по себе не задаёт направление. Изменение расстояния до иконки и смещение карты используются для проверки прогресса.
- Есть встроенный поиск цветных зелёных/бирюзовых ромбиков эфира и реального белого значка самоцвета с центральной вершиной и двумя нижними лепестками. Две цветные стороны одного значка эфира объединяются в одну цель. Обычные круглые белые точки не считаются самоцветами. При отсутствии иконок программа продолжает патруль.
- Основная миникарта берётся из стандартной области справа сверху, как на присланных кадрах. Нижняя карта дорог в этой версии не используется: ресурсов на ней нет.
- При бледной дальней подписи сначала находится эмблема сбора над ней, затем распознаётся только небольшая область текста под эмблемой. Один значок без прочитанного разрешённого имени не запускает F.
- Когда появляется название, движение и камера останавливаются. Координаты повторно уточняются после открытия курсора. Для эфира точка смещена ниже надписи, к маленькому светящемуся объекту; для сапфира дополнительно находится синее тело кристалла. Если нажатие на тело не подтвердило выбор, есть отдельная попытка по известному хитбоксу чуть ниже названия. Оба варианта взаимодействия разрешены игрой.
- Одно A выбирает предполагаемый ресурс. После этого проверяется чёткое имя в верхней плашке. Если оно входит в разрешённый список, программа отпускает Alt и отправляет F для автоподхода. Если дальняя подпись была прочитана неточно, фактическое имя берётся из верхней плашки. При неизвестной/неразрешённой цели F не отправляется. Предусмотрены ограниченные попытки уточнить высоту точки, если первое A не выбрало цель.
- Окно сбора определяется по надписи «Неудача», присутствующей и при пустой полосе. Оранжевые детали местности и синяя полоса питомца больше не считаются окном сбора.
- OCR работает отдельно от навигации и не удерживает её на время распознавания. Его старый результат не может отменить новую цель, уже выбранную A. Если управляющий цикл перестаёт обновлять стики, они автоматически сбрасываются примерно через 450 мс.

## Подход, полёт и сбор

Основной список: **Сапфир, Рубин, Алмаз, Эфир**. Орихаркон не выбирается.

После одного A и стартового F программа отслеживает дистанцию до подтверждённой цели. При близком ресурсе, подсказке F или панели добычи включается **F раз в секунду**. Таймер выполняет Lua независимо от скорости OCR.

Выбор A может сразу запустить штатный автопуть самой игры; программа после проверки плашки дополнительно отправляет F. Во время автоподхода стики остаются нейтральными. Для эфира игра сама открывает крылья: видимая дуга энергии учитывается как уже начатый полёт, лишнее V не отправляется.

Таймер учитывает новую лучшую дистанцию: колебания OCR вроде 12–13–12 м не считаются продвижением. Если расстояние до цели не уменьшается дольше `approach_stall_seconds` (по умолчанию 6 с), запускается ограниченное восстановление:

1. Если крылья уже открыты — один повтор F по существующему таргету, без нового A и без V. Для эфира при нечитаемой дуге тоже разрешён только один повтор F: слепое V не отправляется, поскольку игра сама выполняет взлёт.
2. Если крылья закрыты и энергии достаточно — V, ожидание видимой дуги до 3,5 с, затем F по тому же таргету для штатного автополёта.
3. Если энергии для нового полёта мало — для наземной цели одна попытка прыжка и повтор F.
4. Если сближения по-прежнему нет — узел временно пропускается. Перед возвратом к патрулю отправляется короткий импульс стика назад, затем нейтраль, чтобы запросить отмену старого автопути. Эффективность этой отмены нужно проверить в игре.

Даже дистанция 1–3 м больше не считается доказательством начавшегося сбора: вблизи включается F, но контроль застревания продолжает работать, пока не появится подсказка F или настоящее окно добычи.

Во время сбора наземного ресурса подтверждённые раскрытые крылья закрываются для экономии энергии, F продолжает работать. **У эфира крылья остаются открытыми до исчезновения ресурса**, даже если последняя полоса результата уже заполнена. Когда плашка и полоски цели исчезли и выдержана задержка подтверждения, F отключается и отправляется одно V, если видимая дуга подтверждает открытые крылья. При неудачном подходе V не отправляется для слепого переключения крыльев.

Завершение ресурса определяется по исчезновению верхней плашки/полосок и её имени. Краткие пропуски пережидаются. Старая строка OCR или оставшаяся панель результата не удерживают F после исчезновения самой цели.

## Энергия крыльев

Дуга сначала проверяется как изогнутый HUD с контрастным заполнением/пустой дорожкой. Голубое небо и зелёное свечение сами по себе не доказывают полёт или наличие энергии. Отсутствие дуги не означает 0%.

Параметры в settings_gather.json:

- `flight_low_percent: 8` — при известном остатке ниже этого значения новые воздушные цели откладываются.
- `flight_resume_percent: 18` — возврат к воздушным целям после восстановления.
- Пока эфир отложен, выбираются наземные иконки и продолжается патруль. На земле скрытая энергия оценивается по последнему измерению и прежнему приближению восстановления 0,55 п.п./с; это оценка, не чтение памяти игры.

Выбор 8/18% — настраиваемые пороги этой версии, а не измеренные точные границы игры. Если измерения энергии ещё не было, программа не выдумывает нулевой остаток.

## Миникарта и диагностика

При стандартном расположении, как на присланных скриншотах, отдельная настройка не требуется. Если миникарта перемещена или масштаб интерфейса сильно отличается, остаётся кнопка «Настроить миникарту / добавить иконку»: выделить область карты, свой значок, затем одну известную иконку. Это уточняет область и добавляет реальный шаблон.

Кнопка **«Диагностический кадр через 3 с»** останавливает скан и делает кадр игры. В `debug_gather` сохраняются PNG с найденными иконками/точкой нажатия и JSON с направлением камеры, энергией, именем, дистанцией и полосками. Затем запуск снова через Ctrl+F8. Эти файлы помогают проверить реальные белые значки и направление движения на вашей системе.

Полный журнал — `gather.log`. Есть кнопки копирования и сохранения журнала. Не добавляйте служебную папку `__pycache__` к следующему отчёту: для разбора нужны журнал, настройки и диагностические кадры.

## Управление

- Ctrl+F8 — старт / пауза.
- Ctrl+F9 — остановка ввода программы, сброс A и стиков, отдельная отправка STOP в Lua.
- Ctrl+F10 — заглушить текущую тревогу.
- Ctrl+F9 останавливает ввод программы. Для отмены уже запущенного автопути самой игры при необходимости используйте физическое движение: нейтраль стиков сама по себе не гарантирует отмену маршрута.

Детекторы CAPTCHA/смерти и их эталоны сохранены из исходного v26. Проверки работают отдельными потоками при активном скане, включая движение и сбор. Тревога останавливает ввод, включает соответствующий звук и требует ручного продолжения. Выход звука задаётся `audio_device`, прежнее значение — AG271QG4.

## Проверка сборки

Проходят **44 теста** навигации, порядка ввода и распознавания вырезок, а также исходный `test_offline.py`. Команды для проверки без игрового ввода:

```
python -m unittest test_navigation test_reference_crops -v
python test_offline.py
```

Проверены все семь кадров из присланного PDF:

- Правильный ресурс распознаётся на 7/7 кадрах, включая две бледные дальние подписи, ранее пропущенные программой.
- В последнем кадре верхняя плашка читается как «Сапфир, 49 м» с тремя попытками.
- Направление конуса определяется на 7/7 кадрах; на наземных кадрах находятся реальные белые значки самоцветов. Две части одного цветного значка не дублируются.
- На этих кадрах нет окна добычи и раскрытых крыльев: программа их тоже не обнаруживает. Ранее три кадра ошибочно считались окном сбора.
- Дополнительно проверены прежний ресурс с дистанцией 10 м, сбор сапфира в 1 м, настоящий полёт и окно добычи. Низкий остаток энергии проверен на контролируемой картинке.

В сборку включены только небольшие вырезки интерфейса для тестов и эталоны значков. Полные новые скриншоты, PDF и переписка из них не публикуются.

Полное прохождение рельефа и новая работа стиков в живой игре здесь не проверены. Это исправленная сборка для следующего игрового прогона; прыжок и полёт — ограниченные попытки восстановления, не полноценная 3D-навигация по любой местности.

Дальность выбора 40–50 м не считается гарантией чтения мировой надписи: верхняя плашка служит окончательной проверкой имени. Когда дальняя подпись не распознаётся, патруль продолжает сближение. Дальний значок помогает найти область слабой подписи; без подтверждённого имени программа продолжает сближение.

Старые документы находятся в docs/history и относятся к прежним версиям.

Большая карта M не используется для маршрута. Пользователь проверил все кнопки тестера: только A дал видимый результат как ЛКМ, аналог ПКМ не найден. Навигация использует миникарту, стики и штатный автопуть/автополёт к выбранному ресурсу.

# ACore2 GatherScanner EXP126

[Скачать накопительный патч ZIP](https://github.com/bdmwoosa777-coder/leamstat/raw/refs/heads/main/gather-scanner-exp126/ACore2_EXP126_FAST_MAP_NET_WINGS_PATCH.zip)

EXP126 включает исправления EXP123, EXP124 и EXP125, а также ускоренную привязку карты, проверку назначения по пакету 0391 и обработку маршрутных крыльев по сетевым данным.

Установка: закрыть бот, распаковать ZIP в папку с app.py с заменой файлов. Поддерживается присланная экспериментальная EXP122 (папка v111, база v110), а также EXP123–125. Предыдущие патчи отдельно устанавливать не нужно. Это патч, а не полная сборка: модели, Lua, макросы и настройки остаются из установленной версии. Заголовок после запуска: EXPERIMENT v126.

Инструкция, отчёт проверок и контрольные суммы runtime находятся внутри ZIP. Сырых сетевых записей и видео в архиве нет. Живой запуск EXP126 в Windows/AION2 в среде разработки не проводился.

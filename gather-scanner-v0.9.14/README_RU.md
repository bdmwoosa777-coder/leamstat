# ACore2 GatherScanner v0.9.14 — курсор геймпада LB+LT

В этой версии исправляется контекст передачи A и поиск уже собираемого
ресурса с перекрытой подписью. Повторы клика сохранены. Lua и сетевой EXE
не изменялись.

## Что показали снимки

Красные крестики находятся внутри значка ресурса. Предположение о промахе
из-за сдвига точки на 14 пикселей не подтвердилось по этим изображениям.
На полном кадре игра показывает: в полёте A — «Быстрый полёт», а курсор
геймпада удерживается сочетанием LB+LT. До этой версии отправлялся A при
клавиатурном Alt. Наблюдение Alt в Windows не подтверждает контекст A
в интерфейсе геймпада. Этот риск теперь исключён на уровне отчётов Xbox.

Другой отказ воспроизведён на самих кадрах: выбранная плашка имеет зелёные
стрелки, а название гильдии перекрывает слово ресурса. Старый шаблон стрелок
и чтение букв не находили точку. После сброса выбора исчезают также стрелки,
но белый ресурсный значок остаётся видимым.

## Передача клика

1. Подтверждается клавиатурный Alt и включается курсор Xbox: LB+LT.
2. До первого A выдерживается 140 мс. Курсор устанавливается после подготовки
   этого режима; затем остаются проверки свежего кадра и наведения из v0.9.13.
3. A нажимается при уже удерживаемых LB+LT. Отпускание A также передаётся
   с удерживаемыми LB+LT, чтобы не превратиться в обычное действие полёта.
4. При собственном сборе модификаторы могут оставаться между повторами.
   Они освобождаются перед камерой, боем, закрытием крыльев и выходом из Alt.
   Ctrl+F9, потеря фокуса, ошибка отправки или таймаут также освобождают ввод.

Отдельный watchdog ограничивает забытое удержание курсора примерно двумя
секундами. Новый запрос продлевает срок. Движение стиков не является частью
подготовки LB+LT. Одиночный A без подготовленного режима курсора в новой
политике запрещён. В журнале будут NATIVE_CURSOR и «Xbox TX: LB+LT+A».

Проверка клавиатурного Alt сохраняется: она полезна для доставки курсора
и подтверждения работающего Lua. Теперь её дополняет нативная комбинация
геймпада. Повторы A по свежей точке остаются разрешёнными при active=True.
F для сбора в обычном сетевом режиме не передаётся.

## Поиск значка при перекрытых буквах

Добавлен эталон зелёной стрелки. Выбранный ресурс ищется по паре стрелок
и белому значку без обязательного чтения букв. Если выбор временно сбросился,
уже подтверждённый собственный ресурс можно восстановить по форме значка.
Поиск предпочитает ближайший к предыдущей точке значок, проверяет область
мира и исключает интерфейс миникарты/чата. При отсутствии прежней точки
неоднозначный результат отклоняется.

Эта возможность относится только к уже подтверждённому собственному сбору.
Она не разрешает брать новый неизвестный объект по одному белому значку.
Привязка к своему персонажу, потоку, ID ресурса и проверки selected сохраняются.
После нахождения значка его положение локально проверяется перед каждым A.

При восстановлении уже своего ресурса свежая точка получает клик до
движения камеры. На новое начало оставляется одна секунда. Если точка
не отвечает, небольшие изменения ракурса по-прежнему доступны; свежая
картинка сама по себе не продлевает общий срок восстановления бесконечно.

## Запуск

1. Закрой старую программу и распакуй весь архив в новую папку. Запусти START.bat.
   INSTALL_ONCE.bat нужен только при отсутствии прежних зависимостей.
2. В игре — режим управления 2. G HUB — прежний профиль бота, встроенная память OFF.
   Lua менять не нужно. Физическая G9 включает приёмник Lua.
3. Ctrl+F8 — запуск, Ctrl+F9 — стоп. Оставь встроенную сеть включённой,
   «Только наблюдение» выключенным. Бот сам удерживает LB+LT при клике.
4. После удаления старой папки укажи подходящий наклон заново: в последнем
   запуске использовалось 940 мс. Начальное значение архива остаётся 770 мс.

native_cursor_chord включён в приложении и settings_gather.json; отсутствующее
поле также считается включённым. Не требуется назначать A другой кнопке
или менять физические кнопки мыши.

## Диагностика и ограничения

CLICK_POINT, CLICK_FEEDBACK, INPUT_STATE, PAD_REPORT и NET_COLLECTION сохраняются.
debug_clicks содержит до 24 небольших областей клика с красным крестиком;
debug_gather — прежние диагностические кадры. Файлы хранятся локально и
автоматически никуда не отправляются.

На всех трёх присланных полных кадрах новый поиск нашёл свежий значок.
В проверке контроллера для каждого кадра выполнен один запрос A с LB+LT
без движения камеры. Это воспроизведение на изображениях с драйвером-заглушкой,
а не запуск Windows/AION2/G HUB. Причину каждого серверного удаления снимок
сам по себе не доказывает; реакция игры на новую комбинацию требует проверки.

806 автоматических тестов проходят. Подробности — VALIDATION_RU.md.

Защита от ударившего моба, сохранение ID после боя, запрет левого стика
при собственном неполном ресурсе, контроль крыльев и приоритет эфира 20/35%
остаются прежними. Сетевое позиционирование использует только поддерживаемые
сообщения и свежую свою позицию; при её отсутствии — миникарту. Геометрия
скал, непрерывное сетевое GPS и ИИ-зрение в этой версии не добавлялись.

В архиве нет новых присланных полных кадров, журналов и захватов сети. Новые
тестовые эталоны содержат только ресурсный значок/стрелки; имена, гильдия,
чат и интерфейс персонажа в них отсутствуют.

# Проверка GatherScanner v0.12.12

Полный прогон: 1557 tests, OK, без пропусков.
Среда: Linux/Python 3.12, OpenCV (один CPU поток), Tesseract rus/eng, lupa,
тестовый HTTP и отчёты виртуального Xbox без драйвера/игры.

27 новых сценариев test_course.py проверяют:

- два близких маркера за сектором камеры не получают вертикального обзора;
  близость к персонажу не отменяет проверку сектора;
- свежий конус запрещает сканирование, даже если старое сглаженное направление
  показывало на ресурс; измеренная биссектриса также используется для движения;
- точка внутри измеренного сектора начинает обзор, а близкая к границе сначала
  получает подход/поворот; в журнале есть половина угла;
- выход точки или камеры за сектор отменяет активный обзор; временная потеря
  границ приостанавливает его, длительная возвращает наклон;
- дальний маркер снова получает подход вместо 60-пиксельного обзора; переход
  через 0/360 градусов рассчитывается по кругу;
- две реальные нарисованные границы дают биссектрису и ширину; совместимый
  интерфейс cone_heading по-прежнему возвращает два прежних поля;
- начальный A по ромбику без подтверждения выбора переводит в VERIFY_EMBLEM,
  не отправляет второго A/F и не даёт ручного перемещения;
- повторные вызовы захвата при незавершённой операции не запускают её заново;
- воспроизведение задержки 1.25 с даёт один A, поздний выбор принимается как
  тот же автоход, исходное время отправки сохраняется;
- собственное начало до подтверждения профиля передаётся сбору без A;
- ожидание конечно, NPC не считается ресурсом, другая сессия отменяет ожидание,
  потеря фокуса/сети не разрешает новый ввод;
- возврат без добычи не перебивает короткое ожидание первоначального подхода;
- частично распознанный свободный курс не заменяется боковым маршрутом;
- опасная граница с одной стороны оставляет вторую сторону доступной;
  подтверждённый перепад или опасные обе стороны запрещают манёвр;
- короткий разрыв обработки не заставляет начатый манёвр вращать камеру;
- выпускная скорость подхода .90; продвижение автохода не вызывает коррекцию
  ракурса; время вертикального обзора не старит таймер ходьбы у препятствия.

Три старых тестовых файла обновлены под требования пользователя: дальний/почти
верхний маркер больше не обходит проверку направления; навигатор предлагает
движение во время поворота (движок по-прежнему проверяет поверхность); при границе
с одной стороны активный манёвр выбирает другую. Другие тесты включены без
изменения. Реальный цикл трёх попыток, защита, CAPTCHA, смерть, сброс устройств,
таймеры восстановления, карта и предыдущая память соседей остаются в прогоне.

Аудит ZIP сравнивает веса моделей, распознавание подписи/эмблемы, сетевой декодер,
collection_cycle.py, GamepadInput, XboxBridge, зависимости и бинарные модули с
v0.12.11. Они не менялись. Изменены ожидание первоначального захвата до выбранного
ID, проверка сектора, планирование движения и выпускная скорость.

Журнал показывает два начальных A по одному ромбику с разницей около 1.25 с,
последующее ожидание 42 м без собственного начала и коррекции подхода. Передача
второго A могла отменить игровой маршрут; собственное начало до неё не было
подтверждено. Офлайн-сценарий проверяет устранение повторной передачи, а не
объявляет все действия клиента доказанными по логам отправленных команд.

Проверки не измеряют качество распознавания нового игрового кадра, реальную
скорость бега, коллизии, успешность выделения границ конуса на скриншоте или
эффективность фарма. Windows/AION2/DirectML/ViGEmBus/Ollama здесь не запускались.
Пороги распознавания бледных слов не изменялись. Пользовательский журнал и новый
полный скриншот не публикуются и в архив не включены.

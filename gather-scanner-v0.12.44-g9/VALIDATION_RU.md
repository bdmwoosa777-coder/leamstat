# v0.12.44 MAP: исправление запуска G9

14 целевых тестов выполнены успешно, без пропусков. Реальный новый Lua исполнялся
в LuaRuntime с виртуальным каналом lock-клавиш. Проверены запуск событием мыши 9,
отсутствие запуска от кнопок 5/8, отсутствие опроса G9 через IsMouseButtonPressed,
PING без действий, M и отдельная F вопроса полёта, последовательность numminus →
num5 с включённым Num Lock, отмена клика и отсутствие повтора при потерянном ACK.

В app.py и map_autopath.py изменены только текстовые подсказки про G9.
Алгоритм карты, сбора, сети, моделей и настроек не изменён. Lua принимает прежние
четыре команды; изменены запуск и способ ожидания, без игровой команды при G9.
Приёмник можно оставлять включённым; Ctrl+F9 останавливает Python-бот.
Save & Run заново загружает Lua, затем G9 снова включает приёмник.

Для исходной полной v0.12.44 ранее прошли 2454 теста. Полная регрессия повторно
не запускалась для этой замены кнопки/подсказок. В этом Linux-окружении нет G HUB
и AION2: живое событие физической G9 требует проверки на ПК пользователя.
Пользовательские настройки, эталон карты, журналы и модели не включены в патч.

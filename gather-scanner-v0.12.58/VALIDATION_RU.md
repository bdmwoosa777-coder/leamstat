# Проверки v0.12.58 PLAN

58 новых проверок: test_plan58 (26), test_recovery58 (32).
Профильный прогон: 312 тестов. Полный прогон: 2833 теста.
Сборщик патча требует OK без пропусков в новом, профильном и полном
прогонах. Полный прогон относится к итоговому исполняемому коду.

## Подготовка следующей цели

Проверены расстояние, приоритет/энергия, исключение текущего ресурса,
исчерпанных/чужих объектов, ограничения зоны и отложенных мест.
Входные записи неизменяемы; матрица проекции копируется. Каталог
проецируется один раз и повторно используется. Одновременно допускается
только одно задание. Остановка не ждёт расчёта и не принимает его
поздний результат. Фоновому коду не передаётся движок или устройство.

Интеграционные проверки запрещают захват экрана/движение при расчёте,
проверяют неизменность активного сбора, ID и числа попыток. Следующее A
для того же ресурса действительно передаётся, пока фоновый расчёт
заблокирован. В настоящем tick контроллера план запускается при GATHER
без открытия карты. Без собственного сбора/между попытками/в SEARCH
новое задание не запускается. Ошибка worker не останавливает сбор.

Выход проверяется заново: исчезнувшая цель не навязывается старым
планом, новая ближняя живая точка выигрывает, свежая позиция карты и
энергия меняют порядок. Смена персонажа/карты, потеря сети и Stop
сбрасывают план. Пропущенные XYZ своего ресурса допускают только
приблизительный ориентир последней доставленной цели.

## Ошибки по последнему журналу

- Неизвестный сетевой template при собственном старте и привязанном
  имени того же ID действительно выдаёт вниз отчёт Xbox перед Tab.
  Имя другого ID или отсутствие имени такого права не дают. Известный
  наземный тип перекрывает старое визуальное имя эфира.
- Нет ответа Tab: один другой нижний ракурс и повтор; следующая такая
  ошибка завершает ограниченный эпизод. Передача атаки требует
  выбранного ID источника урона, прежние проверки защиты сохранены.
- После убийства в режиме автопути перед повторным выбором действительно
  выдаются отчёты возврата pitch, без полной калибровки и левого стика.
  Новый свой старт не получает этих отчётов. Время отчётов не выдаётся
  за прямое измерение угла игровой камеры.
- Провал воздушного боя сохраняет один возврат к ID. Старый прерванный
  attempt_active не подтверждает успешный возврат. Новый собственный
  старт подтверждает его. При отсутствии XYZ доступна последняя
  соответствующая цель. До ready_at новый маршрут не запускается.
- Полный собственный результат исключает место даже без template/XYZ
  по сохранённой связи со своим ID/доставленной целью. Частичный/чужой
  результат или сменившийся персонаж не исключают точку.
- Три наблюдения пустой мини-карты в справочном месте не выдают UP;
  отсутствие самого радара не считается отсутствием ресурса. Появившаяся
  отметка возобновляет осмотр; при дальней отметке сначала меняется
  направление камеры. Пять дополнительных проверок реального захваченного ромба: точно
  в центре при разных масштабах, поверх белой стрелки, запуск полного
  осмотра по обнаруженному центральному эфиру. Отдельно проверены
  белая стрелка, красный моб, бирюзовая окружность и зелёная галочка: они
  не становятся эфиром после снятия центрального запрета. Четыре
  проверки перекрытия красными отметками: центральный моб помечает
  наблюдение как закрытое, но не превращается в эфир; цель получает
  ограниченный осмотр без движения; далёкий моб не мешает обнаружению
  пустой точки; осмотр при перекрытии не зацикливается. Видимая подпись прерывает осмотр.

Прежние проверки собственного полного сбора, орихаркона, алмаза,
крыльев, мини-карты, защиты, фокуса, сетевого контекста, карты и
протокола включены в полный набор. CollectionCycle, Lua v48, G9,
AION_MAP_RMB/G5, Mouse Keys/lock-key протокол и Num Lock не менялись.

Аудит проверяет Python AST/JSON, состав изменений, точное сохранение
карты/каталога/привязки v56, CRC архива, уникальность путей Windows.
Тесты, настройки пользователя, журналы, снимки, новые модели в ZIP
не входят. Патч ставится на v56 или v57 и содержит исправления v57.

Публикация: четыре файла ZIP/README_RU.md/VALIDATION_RU.md/SHA256SUMS
в новой папке и новой ветке от свежего main. main и прежние выпуски
не меняются. Все четыре файла скачиваются обратно по фиксированному
commit и сравниваются побайтно и по SHA256; ZIP проверяется по CRC.

В этой среде нет запущенной Windows/AION2/G HUB. Офлайн-проверки
подтверждают код и отчёты виртуального контроллера в тестах, но не
доказывают успешность живого боя/сбора в конкретной игровой сцене.

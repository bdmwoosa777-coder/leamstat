# Проверки v0.12.61 BOSS

20 новых проверок (test_boss61), 119 профильных, 2880 в полном наборе.
Сборщик требует OK без пропусков во всех прогонах итогового кода.

Новые проверки:

- Карточка требует заголовка, оставшегося времени, основных трофеев и
  обычной кнопки перемещения. Только таймер/только трофеи, покупка или
  телепортная кнопка не подтверждают этот тип карточки.
- Заголовок и кнопка связаны с текущим кадром; смена текста/размера
  отзывает подтверждение. Обычная карта без панели не вызывает OCR
  карточки при каждом закрытии карты.
- Значок под точкой больше не запрещает единственное ПКМ к ресурсу.
  Только карточка после нашего запроса переводит в шаг перемещения.
- Реально передаётся одна обычная UI-A по проверенной кнопке. Нет
  ATTACK_PAIR, Tab, RB, V, F сбора или движения левым стиком. Исходная
  цель-ресурс сохранена. Сохранение окна после A не повторяет кнопку.
- Передача A сама не подтверждает движение. После закрытия карты
  проверяется HUD; маршрут завершается по собственным близким данным.
- Изменившаяся карточка, окно/фокус, отсутствие нашего запроса, уже
  завершающийся неудачный маршрут и новый собственный сбор не получают
  кнопку. Смена карточки во время наведения отзывает ввод без повтора.

Один тест v60 уточнён: существующая карточка до нового ПКМ блокирует
его; сам значок больше не является таким запретом. Остальные 25
проверок v60 и проверки предыдущих сборок сохранены в полном наборе.

Python AST/JSON, точный состав изменений, неизменность Lua/проводного
протокола/Num Lock, CollectionCycle, сети, карты/каталога и настроек
проверяются сборщиком. Архив проверяется по CRC и уникальным именам
Windows. Тесты, журналы, снимки и пользовательские настройки не входят.
Патч включает предыдущие исправления и совместим с v56–v60.

Публикуются только ZIP, README_RU.md, VALIDATION_RU.md и SHA256SUMS
в новой папке/ветке от свежего main; main и старые выпуски не меняются.
Четыре файла скачиваются обратно по фиксированному commit и сверяются
побайтно и по SHA256, ZIP дополнительно проверяется по CRC.

Ограничение: реального AION2/G HUB здесь нет. Проверены распознавание
на синтетических состояниях карточки, логика разрешения кнопки и
отчёты виртуального Xbox. Запуск именно этой кнопки на ПК пользователя
не объявляется доказанным по одному офлайн-прогону.

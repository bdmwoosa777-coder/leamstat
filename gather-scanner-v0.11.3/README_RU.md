# GatherScanner v0.11.3 — полный ответ Ollama и курс на открытой земле

В последнем журнале Qwen возвращала корректные ответы примерно за 2–2,5 с,
и один ANALYZER_PLAN был принят. Позже поступали пустые сообщения done=False.
Такая запись ещё не означает завершение генерации, однако прежний клиент
обрабатывал её как пустой ответ. Теперь явно запрашивается stream=true,
NDJSON-фрагменты собираются до done=true, затем проверяется полный JSON.
Обрыв до финальной записи — отдельная ошибка, незавершённый текст не принимается.

## Установка и запуск

1. Закройте прежнего бота, распакуйте новую папку и выполните SETUP.bat.
2. Если Ollama уже установлен и qwen2.5vl:3b скачана, переустановка модели
   не нужна. SETUP_ANALYZER.bat запускает/проверяет её с использованием кэша.
3. При закрытом боте запустите CHECK_ANALYZER.bat. Отчёт analyzer_check.json
   содержит ответ синтетического теста, длительность и /api/ps с size_vram.
4. При valid_answer=true запускайте START.bat. Включены анализатор Ollama,
   локальные ONNX через DirectML, поиск ресурсов и именованный возврат карты.
   Ctrl+F8 — запуск, Ctrl+F9 — стоп. Нужны прежние Npcap/ViGEmBus/Tesseract.
5. Lua совместим с v0.10.2–v0.11.2; менять его повторно не нужно. Включите
   приёмник G9 в профиле G HUB. Физический F710/USB-приёмник отключите.

Python x64 3.10–3.13, предпочтительно 3.12. Камера по умолчанию 940 мс.
Модель хранится вне папки бота, в кэше Ollama. Белое окно Ollama не показывает
состояние запросов бота; открывать отдельный чат для работы не требуется.

## Навигация и полёт

На распознанной свободной полосе (земля от 70%, объектов менее 15%, нет
поддержанного края по сетке) сохраняется исходный курс Navigator к ресурсу.
Локальный поиск прохода не подменяет его соседними фронтами сетки. Обход
препятствий, выход из области кибелиска и реакция на подтверждённое застревание
сохраняются. Видимая земля не является гарантией физической проходимости.

Параметр «Один пробный подъём крыльями над препятствием» теперь выключен
по умолчанию: один значок миникарты не запускает такой пробный взлёт.
Штатный подлёт после выбора видимого эфира и спасение при подтверждённом
застревании сохраняются. Если переносите старые настройки, снимите эту галочку
вручную. Иначе сохранённое пользователем true останется включённым.

Из v0.11.2 сохранён управляемый спуск после неудачного осмотра при спасении,
без объявления посадки по таймеру. Общий предел спасения 45 с. Последующие
процедуры возврата также сохранены. Изменения не гарантируют выход из любой
скалы и не добавляют точную 3D-карту/запоминание обходов между запусками.

## Что означает участие Qwen

Используется Qwen2.5-VL 3B. Запрашиваются только route_id и scene, минимальная
схема из двух полей передаётся Ollama, в тексте дан пример значений. Номер
должен существовать в текущем предложении путей. Команды модели не исполняются.
Окна карты, сбор, бой и полёт обслуживает код бота. Рамки эфира модель больше
не выдаёт: распознавание подписи/ромбика выполняет прежний детектор.

ANALYZER_RESULT — полный JSON получен и проверен. ANALYZER_PLAN — подсказка
совместима с текущим видом и принята планировщиком. Ответ старше 8 с или ответ
после существенного изменения вида не используется. Поэтому наличие правильного
JSON ещё не гарантирует помощь в игре. Некоторые проблемы движения остаются
возможными и при работающей модели.

CHECK_ANALYZER не захватывает игру и не нажимает кнопки. Он сохраняет текст
ответа только для нарисованной тестовой картинки. Если ошибка повторяется,
нужны новый analyzer_check.json и журнал запуска. CHECK_ROUTES.bat позволяет
посмотреть пути по выбранному кадру без игрового управления.

## Проверки и лицензии

Проверки: VALIDATION_RU.md. В этой среде нет живых AION2/Windows/Qwen/RTX 4080;
уменьшение ошибок API и улучшение движения в игре требуют проверки пользователя.
Две ONNX, Lua и сетевой EXE сохранены. NVIDIA SegFormer — некоммерческая оценка/
исследование; Depth Anything V2 Small — Apache-2.0. Условия: VISION_THIRD_PARTY.md
и models/. Веса Qwen в ZIP не включены. Используется только локальный Ollama.
История v0.11.2: docs/history/README_V0112_RU.md. Новые личные логи, полные кадры,
захваты, диагностические JSON и окружение Python в публикацию не включаются.

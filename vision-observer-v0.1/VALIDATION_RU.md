# Проверка Vision Observer 0.1

## Выполнено

- Экспорт настоящего SegFormer B0 / ADE20K из зафиксированных весов
  `489d5cd81a0b59fab9b7ea758d3548ebe99677da`. SHA-256 исходного safetensors
  проверен; модель загружается локально, без исполняемого кода репозитория.
- ONNX checker проверил граф. На одном и том же случайном входе результаты
  исходного PyTorch и ONNX Runtime совпали с максимальной абсолютной разницей
  **0.0000209808349609375**. Вход — float32 `[1,3,512,512]`, выход — 150 классов.
- Реальный запуск ONNX на CPU: синтетический кадр и два прежних игровых
  изображения. Обработка игровых изображений заняла примерно 347–381 мс
  на процессоре этого окружения. Это не измерение RTX 4080.
- Графическое окно запущено под Linux/Xorg с виртуальным дисплеем. Проверены
  результат реального вывода модели, русские надписи, масштабирование картинки,
  изменение порога и сохранение примера. Приватные скриншоты проверки не включены.
- Обработка короткого видео через командную строку с сохранением трёх примеров.
- Для Windows x64 / Python 3.12 проверено получение колёс ONNX Runtime DirectML
  и остальных зависимостей с PyPI. Это проверка доступности установки, не запуск
  DirectML на Windows.

## Автоматические сценарии

22 теста в `test_observer.py`:

- Зелёная группа не объявляет маршрут доказанным. Неизвестный/неуверенный класс
  не становится землёй. Вода, строения и небо различаются. HUD исключён.
- Граница земли с небом/водой рисуется как визуальная подсказка; неверные
  размеры и NaN отвергаются.
- Исходный кадр, классы, уверенность и метаданные сохраняются согласованно.
  Повторные сохранения не перезаписывают друг друга. Ошибка диска не оставляет
  завершённый частичный пример. Архив включает только готовые примеры.
- Другое активное окно не захватывается; смена фокуса во время захвата
  отбрасывает кадр. Возвращается только клиентская BGR-область. Чёрный кадр
  вызывает диагностическую паузу.
- Старый результат в очереди заменяется новым. Лимит автосохранения — 60
  примеров за сеанс. Ошибка модели появляется в состоянии окна и завершает поток.
- Проверены BGR→RGB, нормализация и размеры вывода. Повреждённая модель
  отвергается до создания сеанса. Выполняется один реальный ONNX inference.

## Что не проверено

Нет живого запуска Windows/AION2 и RTX 4080. Перечисление DXGI-адаптеров,
DirectML, захват настоящего окна игры и горячие клавиши нуждаются в проверке
у пользователя. Win32-проверки захвата в автоматических тестах используют макеты.

Модель не обучена на AION2, уверенность не откалибрована для этой игры.
Нет точной глубины, карты столкновений, проверки мостов на проходимость или
гарантированного распознавания обрывов. Идентификация ресурсов не добавлена.
Получившиеся цвета — материал для оценки, не основание включать автодвижение.

В тестере отсутствуют отправка игровых нажатий, эмуляция мыши/геймпада,
инъекции в игру, чтение игровой памяти и сетевой перехват. Во время наблюдения
нет сетевой отправки изображений. Пользовательские кадры, журнал и примеры
не входят в публикуемый архив.

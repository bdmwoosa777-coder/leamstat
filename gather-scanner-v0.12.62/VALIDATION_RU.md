# Проверки v0.12.62 SKIP

34 новых проверок test_skip62; 214 профильных; 2914 в полном наборе.
Сборщик требует OK без пропусков во всех прогонах итогового кода.

Новые проверки воспроизводят:

- Отсрочку 5/10/15 минут с конечным сроком и увеличением только
  для повторной неудачи поблизости. Другой ID/каталожный дубль не
  обходит отсрочку; другой тип ресурса и соседняя точка не блокируются.
- Новую сетевую генерацию после осмотра, снятие пропуска собственным
  положительным событием, неизменяемый снимок для фонового планировщика.
- Сохранение остатка времени после перезапуска, изоляцию разных карт,
  возврат на предыдущую карту, сохранение снятого пропуска, отсутствие
  записи на диск при каждом кадре собственного сбора. Повреждённые,
  нечисловые и неограниченные данные, истёкшая история и обратный ход
  системного времени не создают вечных запретов и не останавливают код.
- Далёкую иконку при пустом справочном месте: нет UP/движения/поворота,
  за три кадра осмотр заканчивается. Появившаяся близкая иконка снова
  допускает осмотр. Центр под красными мобами и живая цель из сети
  сохраняют ограниченную проверку при невидимой иконке.
- Описание зоны требует тёмной панели и текста разделов, не путается
  с карточкой босса. X находится на изображении; общий X карты вне
  области карточки не подходит. Смена надписи/размера/X отзывает ввод.
- После собственного ПКМ описание без перемещения сразу завершает
  неудачный запуск, без второго ПКМ и ожидания HUD. Старое описание
  получает максимум один клик по проверенному X. Потеря фокуса или
  смена карточки блокируют нажатие. Без X выбирается незакрытая часть
  карты, то же ограничение применяется перед окончательным кликом.

Старая проверка test_recovery58 уточнена для близкой отметки (20 px)
вместо дальней (40 px); новый отдельный тест запрещает считать дальнюю
отметку подтверждением справочной точки. Остальные проверки сохранены.

Python AST/JSON, точный состав изменений, неизменность Lua/протокола,
Num Lock, CollectionCycle, сети, карты/каталога и настроек проверяются
сборщиком. ZIP проверяется по CRC и уникальным именам Windows. В нём
нет тестов, журналов, снимков, сохранённых пропусков или настроек.
Патч включает предыдущие исправления и совместим с v56–v61.

Публикуются ZIP, README_RU.md, VALIDATION_RU.md и SHA256SUMS в новой
папке/ветке от свежего main. Main и старые выпуски не меняются. Все
четыре файла скачиваются по фиксированному commit и сравниваются
побайтно/по SHA256; у ZIP дополнительно проверяется CRC.

Ограничения: реального AION2/G HUB здесь нет. Проверены синтетические
изображения, события, сохранение состояния и виртуальный Xbox.
Корректность распознавания описания на ПК пользователя и фактический
прирост ресурсов/минуту этой сборкой здесь не измерены. Отрицательный
осмотр не доказывает истощение, поэтому отсрочки временные.

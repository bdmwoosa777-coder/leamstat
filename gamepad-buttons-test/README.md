# Тест кнопок виртуального Xbox

[Скачать ZIP](Gamepad_Buttons_Test_v0_2.zip?raw=true)

Отдельный тест A, X, Y, B, RB, RT, LB, LT: одно выбранное нажатие через 8 секунд. Нужны уже установленные Python, vgamepad и ViGEmBus. Запуск — `RUN_TEST.bat`, подробности — `README_RU.txt`.

Для проверки маршрута откройте M в игре, наведите курсор на ближайшую точку и отправьте одну кнопку. Проверяйте появление маршрута и начало движения. B может закрыть окно; перед следующим тестом снова откройте карту. Программа не утверждает, что какая-либо кнопка соответствует правому клику.

Каждая кнопка отпускается через 200 мс. Esc или STOP отменяют тест. Перед запуском закройте сборщик и предыдущий тест A, чтобы не создавать несколько виртуальных контроллеров.

# Проверка GatherScanner v0.12.17

Полный прогон: 1669 tests, OK, без пропусков.
Среда: Linux/Python 3.12, OpenCV с одним CPU-потоком, Tesseract rus/eng,
тестовые сеть, HTTP и отчёты виртуального Xbox. Тесты отдельных процессов
запускаются через spawn из настоящего файла с защитой __main__.

## Основание изменения

Последний пользовательский журнал подтверждает отмену выхода из лагеря
из-за признака «ресурс доступен» менее чем через секунду после его начала.
Другой выход прекращён по 35-секундному таймеру без доказательства успеха.
Загрузка обоих процессов анализа и запрос Windows-планировщика в этом запуске
успешны; эта сборка исправляет условия навигации, а не повторяет перенос процессов.

## Новые проверки

27 тестов test_camp_departure.py проверяют:

- направление от кибелиска в координатах карты и его сохранение при поворотах;
- выбор начального видимого прохода, запрет слабого/узкого маршрута и обрыва;
- завершение только после измеримого удаления либо собственного сбора;
- масштабирование порогов вместе с миникартой, отсутствие выдуманного успеха;
- сохранение выхода при наличии эфира, передачу настоящих подписей на выбор;
- сохранение данных эфира для политики приоритета, возврат обычной навигации
  после подтверждения выхода;
- перепланирование вместо отмены по таймеру, конечную память неудачного курса;
- запрет возврата неудачного направления через обычный прямой патруль;
- полноценный боковой вектор, прежний вектор обычной навигации к ресурсам;
- поворот перед движением за спину камеры, запрет прямого шага в обрыв;
- запрет подмены выхода обычным патрулём, его наклоном камеры или взлётом;
- возврат реального наклона камеры перед выбором наземного прохода;
- сброс курса при телепортации, сохранение отдельного моста острова;
- отсутствие исключения ресурсов при неудаче прохода;
- сохранение ограниченного бокового взлёта при доказанном упоре в стену.

Пять прежних тестов изменены под новое требование: истечение 35 секунд не означает
завершение выхода, а значок ресурса не означает его доступность. Проверка
повторного обнаружения лагеря теперь сначала подтверждает реальное удаление.
Поворот к лагерному проходу за спиной сохраняет выбранную сторону поворота.

Полный набор также проверяет настоящий spawn/IPC, актуальность кадров,
3/3, 15 секунд, первый A, фокус, связь, бой, карту, CAPTCHA, смерть, обрывы,
ограничение времени стиков и доводку камеры. Новый анализатор/новая модель
не добавлялись. Прямой опыт запуска в Windows/AION2 не выполнялся.

Архив проверяется по синтаксису Python/JSON, CRC ZIP, обратному чтению каждого
файла и SHA256. Модели, зависимости, бинарные компоненты, декодер сети,
Xbox-транспорт, распознавание подписей и изоляция вычислений совпадают с v0.12.16.
Публикуются только полный ZIP, README_RU.md, VALIDATION_RU.md и SHA256SUMS
в новой ветке downloads/gather-scanner-v0.12.17. main не изменяется.
Новые пользовательские журналы, полные скриншоты и кэши не включаются.

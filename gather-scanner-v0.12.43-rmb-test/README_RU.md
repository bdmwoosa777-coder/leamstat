# Отдельный тест ПКМ / виртуального Xbox

Запуск: RMB_TEST.bat. Это отдельное окно, бот для теста закройте.
Лаунчер выбирает уже установленный Python бота; если его нет, использует
текущий Python. Установщики, pip и драйверы он не запускает.
Для прямого теста нужны только Python с Tkinter и Windows. Для режима
виртуального Xbox нужны уже имеющиеся vgamepad и ViGEm, как у бота.

## 1. Прямой ПКМ через Windows

1. Выберите «Windows: ПКМ вместо кнопки Xbox».
2. Переключитесь в AION2, наведите мышь в игровую область.
3. Нажмите F8: удерживается ПКМ. Подвигайте мышь и сравните с физической ПКМ.
4. Ещё F8 — отпустить. F9 всегда отпускает оба возможных вида ввода.

Можно нажать «Тест 2 с через 3 с», за 3 секунды переключиться в игру и
наблюдать двухсекундное удержание. При потере фокуса ввод отпускается.
Закрытие окна также отпускает команды. Если F8/F9 заняты другой программой,
это будет записано в журнале; остаётся отложенный тест.

В этом режиме выбранная Xbox-кнопка вообще не отправляется: вместо неё
вызывается Windows SendInput с RIGHTDOWN/RIGHTUP. Это полноценные по типу
мышиные события, но программные; игра может принимать их иначе, чем
физическую мышь. Строка «передано» означает успешный вызов Windows,
а не доказательство реакции AION2. Если приняты 0 из 1 событий, проверьте,
что игра и тест запущены с одинаковыми правами; авто-повышения прав нет.

## 2. Виртуальная кнопка → ПКМ через Steam Input

Сам протокол Xbox не содержит кнопки мыши. Здесь тест отправляет именно
кнопку контроллера, а мышиное действие должен назначить Steam.

1. Выберите «Steam Input: кнопка Xbox», оставьте X либо выберите другую.
2. Нажмите «Подключить Xbox для Steam». Программа не устанавливает драйвер.
3. Для AION2 в Steam включите Steam Input для Xbox-контроллера. Если игра
   не из Steam, добавьте её/её запускаемый файл как стороннюю игру.
4. В раскладке контроллера назначьте выбранной кнопке действие «Мышь →
   Правая кнопка мыши». Обычное удержание, без переключателя/турбо и без
   дополнительной исходной кнопки. Названия пунктов зависят от версии Steam.
5. Запустите игру через Steam, чтобы применился этот профиль. При необходимости
   перезапустите игру после подключения виртуального контроллера.
6. Переключитесь в игру: F8 нажимает/отпускает выбранную Xbox-кнопку, F9 снимает её.

Без активного профиля Steam режим 2 даёт обычную Xbox-кнопку и не является
ПКМ. Он не вызывает SendInput RIGHTDOWN: можно сравнить два разных пути.
Если Steam не видит виртуальный контроллер или профиль не цепляется к
реальному процессу игры, это отдельная причина отсутствия ПКМ.

Для сравнения сначала проверьте физическую ПКМ, затем режим Windows и затем
Steam. Сравнивайте одно действие на одном и том же месте: например, удержание
ПКМ с движением мыши. Если работает только физическая, оба программных пути
пока не подходят. Если работает Windows или Steam, это подтверждает именно
этот путь на вашей игре. Различие поведения интерфейса геймпада и мыши тоже
поможет понять, дошло ли событие до игры.

Программа сама не меняет файлы/профили Steam и не запускает бота. Его выбор
ресурсов и ввод этим экспериментом не изменены. В этой среде нет Windows,
AION2 и Steam: фактическая реакция игры пока не проверена.

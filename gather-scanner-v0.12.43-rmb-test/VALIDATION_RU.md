# Проверка отдельного теста ПКМ v0.1

15 тестов test_rmb_probe.py прошли в общем наборе 2367 тестов v0.12.43.
Проверены диспетчеризация режимов, отпускание, частичная ошибка отправки,
аварийный сброс, фильтр окна AION2, структура Windows INPUT для разрядности
тестовой среды, RIGHTDOWN/RIGHTUP и отказ SendInput, выбор Python без установки.

ZIP содержит ровно 7 файлов: отдельную GUI-программу, модуль ввода,
лаунчер, BAT, инструкцию и два файла поиска имеющегося Python-окружения.
Файлы побайтно совпадают с соответствующими файлами v0.12.43; README внутри
равен RMB_TEST_RU.md основного архива. Программа не импортирует бота, модели,
захват сети или навигацию. Лаунчер не запускает setup/pip/драйверы.

Здесь нет Windows/AION2/Steam. Успех отправки Windows не доказывает, что игра
приняла программный ввод. Win32 hotkeys, виртуальный драйвер и профиль Steam
Input нужно проверить на Windows по инструкции. Никакого нового ввода в
основном боте этим экспериментом не включено.

Архив проверен по составу, байтам, SHA256 и CRC. Публикуются ровно 4 файла:
ZIP, README_RU.md, VALIDATION_RU.md и SHA256SUMS в отдельной новой ветке downloads.
Пользовательских кадров, журналов, настроек Steam и маршрутов нет.

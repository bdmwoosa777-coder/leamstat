# QUIET TEST: проверка

6 целевых тестов, OK, без пропусков. Настоящие MapKeyWire/MapMouseKeys
v0.12.47 и новый Lua исполняются через Lupa и виртуальный Windows ввод.
SDK PlayMacro/AbortMacro имитируется: реальная игра не воспроизводится.

Проверены ACK приёма раньше вызова SDK; минимум 2 с между отпусканием ACK
и макросом без новых событий клавиатуры; только один запуск после долгого
простоя; отказ без разрешения; отмена при потере фокуса и KeyboardInterrupt
во время ожидания; отсутствие любых нажатий Num Lock. Команды M/F тестовым
Lua не исполняются. Восстановление Caps вызывается только после ожидания.
Синтаксис Python/Lua, состав ZIP, байты, CRC и SHA-256 проверяются.

Живой тест на Windows требует запуска пользователем. Проверка не означает,
что влияние клавиш канала уже доказано. Новая задержка — изменяемая переменная
этого диагностического опыта. Рабочий бот не меняется. Пользовательские
логи, кадры и настройки в ZIP не включены.

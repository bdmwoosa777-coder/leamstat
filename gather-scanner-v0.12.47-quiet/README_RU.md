# QUIET TEST — одна команда, 2 секунды тишины, затем макрос

Пользователь подтвердил: PlayMacro запускается до завершения обработчика
G9. Следующая отдельная проверка отделяет передачу Python → Lua от
вызова AION_MAP_RMB двумя секундами без клавиш канала. Это гипотеза для
проверки, не установленная причина отказа рабочего бота.

## Запуск

1. Бот закройте. Распакуйте ZIP в его папку с START.bat.
2. Вместо временного восьмисекундного теста вставьте в G HUB полный
   GHUB_MAP_QUIET_TEST.lua из этого архива: Save & Run, затем G9.
   G9 включает прослушивание; сам по себе макрос здесь не запускает.
3. Макрос AION_MAP_RMB и назначение G5 оставьте прежними. Num Lock НЕ ТРОГАТЬ.
4. Запустите TEST_MAP_QUIET.bat. За 8 секунд переключитесь в игру,
   откройте большую карту и сами наведите курсор на доступную точку рядом.
5. После наведения не трогайте курсор/окно/карту до конца теста. Подождите
   примерно 20 секунд от запуска, затем закройте M и проверьте автопуть.
6. Пришлите map_quiet_probe.log из этой папки и сообщите результат.

Этот Lua предназначен ТОЛЬКО для TEST_MAP_QUIET.bat. Рабочий бот с ним
не запускайте: ACK команды клика здесь означает ПРИЁМ, а не исполнение,
а команды M/F намеренно запрещены. Ни Python, ни Lua не закрывают карту.
Точка задаётся вручную, нет OCR и автоматического наведения/движения Xbox.

После ACK получения Lua молчит 2 секунды, вызывает PlayMacro(AION_MAP_RMB)
один раз, выдерживает короткую паузу. Python всё это время ничего нового
не передаёт и не восстанавливает Caps. Он наблюдает фокус/курсор/границы;
при их изменении или прерывании ожидания отзывает отложенную команду.
Через 4 секунды ожидания тест закрывает канал и сохраняет наблюдения Windows
о кнопках мыши. RIGHT_DOWN/UP и ACK не доказывают принятие маршрута игрой.
При ошибке наблюдателя отсутствие событий не выдаётся за отсутствие клика.

Рабочие Python v0.12.47, настройки, карта и макрос не меняются.
Тестовые файлы имеют отдельные имена, обычный журнал/тест не заменяется.
Num Lock только читается: команды его переключения отсутствуют.
Виртуальная проверка протокола выполнена; Windows/G HUB/AION2 здесь нет.

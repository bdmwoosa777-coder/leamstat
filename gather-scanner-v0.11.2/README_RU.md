# ACore2 GatherScanner v0.11.2 — короткий ответ анализатора и спуск

Эта версия исправляет протокол обращения к локальной Qwen2.5-VL 3B и первый
переход после неудачного поиска в воздухе. Полноценный автопилот/обучение
маршрутам не заявляются. Ошибки пустых ответов в предыдущем запуске установлены,
но их точная причина ещё требует проверки настоящего Ollama пользователя.

## Запуск

1. Закройте прежний бот. Распакуйте новую папку и выполните SETUP.bat.
2. Выполните SETUP_ANALYZER.bat. Модель qwen2.5vl:3b уже хранится в кэше Ollama,
   если вы применяли патч; повторно скачивать её обычно не потребуется.
3. С закрытым ботом выполните CHECK_ANALYZER.bat. Результат — analyzer_check.json:
   правильность JSON, длительность, версия Ollama и running_models из /api/ps.
   size_vram показывает размещение в видеопамяти; это не измерение FPS игры.
4. Запустите START.bat. Включены локальный анализатор и DirectML-навигация.
   Модель Ollama должна быть запущена. Белое окно Ollama не является индикатором
   запросов бота; вручную начинать чат не требуется.
5. Нужны прежние Npcap, ViGEmBus, Tesseract и приёмник Lua в G HUB (G9).
   Физический F710/его приёмник отключите. Lua совместим с v0.10.2–v0.11.1,
   повторно менять его не нужно. Ctrl+F8 — запуск; Ctrl+F9 — стоп.

Python x64 3.10–3.13, предпочтительно 3.12. При отсутствии: py install 3.12.
Камера по умолчанию 940 мс. Включённые в архив ONNX работают через DirectML,
языковая модель — через локальный Ollama. PyTorch/CUDA в Python не требуются.

## Анализатор

Вместо длинного ответа с объяснением и рамками эфира запрашиваются только
route_id и scene, например {"route_id":2,"scene":"passage"}. Выбирается один
из существующих путей; неизвестный номер/лишние поля отвергаются. В запросе
используется обычный JSON-режим Ollama, а строгая проверка выполняется кодом.
Поле think не отправляется модели без поддержки рассуждений. Лимит генерации
уменьшен с 512 до 96 токенов. Это должно уменьшить задержку, но измерений
на настоящей Qwen одновременно с игрой в этой среде нет.

Короткий ответ не содержит рамок ресурсов: эфир распознаётся прежним детектором
надписи и значка. Qwen не управляет сбором, полётом или окнами карты. Модель может
ошибаться в выборе прохода, а предлагаемые пути также могут быть неверными.

ANALYZER_RESULT означает полученный и проверенный JSON. ANALYZER_PLAN означает,
что подсказка ещё совместима с текущим видом и передана планировщику. Ответ
старше 8 секунд по-прежнему не используется: увеличение срока не делает
устаревшую дорогу правильной. Ошибки API теперь выводятся явно; для пустых
ответов сохраняются имена полей ответа, done, done_reason и счётчики, без
содержимого изображения или внутренних рассуждений.

CHECK_ANALYZER использует только нарисованную тестовую картинку. Если ошибка
повторяется, нужны analyzer_check.json и журнал нового запуска. Этот тест
проверяет протокол и размещение модели, а не качество навигации в AION2.

## Полёт

После короткого перелёта и неудачного осмотра AreaRecovery теперь переходит
в существующие фазы DESC_DOWN/DESCEND: направляет камеру вниз и пробует
управляемый спуск. Раньше этот переход сразу возвращал обычный поиск с крыльями,
и навигатор мог лететь между значками миникарты. V/END_AIR по этому таймеру
не отправляются, посадка по времени не объявляется. Новый собственный сбор
прекращает спасательный манёвр по прежним правилам.

Спуск ограничен по времени; он не доказывает, что внизу безопасная поверхность.
Общий предел спасения 45 с и прежние последующие процедуры сохранены. Это
исправление конкретного перехода, а не гарантия выхода из любой скалы.

Одиночный клик по ромбику, продолжение собственного сбора и второе подтверждение
телепорта из v0.11.1 сохранены. Собственные XYZ в последнем запуске почти всё
время были недоступны/устаревшими: точная навигация по высоте не выдумывается.
CHECK_ROUTES.bat показывает варианты путей по выбранному снимку без игрового
ввода. Сохранённой памяти обходов между запусками пока нет.

## Лицензии и проверки

Полные условия моделей: VISION_THIRD_PARTY.md и models/. NVIDIA SegFormer —
некоммерческое исследование/оценка, Depth Anything V2 Small — Apache-2.0.
Веса Qwen в ZIP не включены. Локальный API: http://127.0.0.1:11434, без облака.
Подробности проверки — VALIDATION_RU.md. История — docs/history/README_V0111_RU.md.
Новые личные журналы, полные кадры, захваты и локальные результаты не публикуются.

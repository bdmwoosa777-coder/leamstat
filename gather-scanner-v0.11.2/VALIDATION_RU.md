# Проверка v0.11.2 ANALYZER_PROTOCOL

Полный прогон: 1131 тест, OK, пропусков 0. Lua выполнен через lupa;
OFFLINE TESTS PASS. Проверки выполняются в Linux без живых AION2/Windows/Qwen.

Четыре новые проверки: корректный короткий ответ расширяется во внутренний
формат без выдуманных рамок эфира; неизвестный номер не обходит проверку;
ошибка в JSON-конверте API выводится явно; неожиданный конверт сообщает имена
полей без содержимого. Настоящий локальный HTTP-сервер проверяет JSON-режим,
изображение и отсутствие think у не поддерживающей его модели.

Проверки AreaRecovery обновлены под намеренное изменение поведения: после
неудачного SCAN сохраняется RESCUE и начинается DESC_DOWN. Движок не передаёт
этот переход обычному навигатору. Прежние сценарии собственных сборов/защиты
сохраняют приоритет. Полный сценарий с медленными кадрами, включая новый спуск,
завершается до общего предела 45 с; автоматического V для закрытия нет.

CHECK_ANALYZER — пользовательская проверка настоящего локального Ollama на
синтетическом кадре с чтением /api/ps. Здесь настоящая Qwen/GPU не запускалась.
Уменьшение задержки, устранение пустых ответов и качество выбора прохода
не объявляются доказанными до такого запуска. Не все проблемы поведения
объясняются моделью: её отсутствие оставляло в работе прежние правила.

Lua, сетевой EXE, ONNX и лицензии побайтно совпадают с v0.11.1. Архив по явному
списку исключает новые личные логи, полные кадры, захваты, venv, analyzer_check.json
и остальные локальные результаты. История: docs/history/VALIDATION_V0111_RU.md.

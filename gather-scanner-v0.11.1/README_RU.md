# ACore2 GatherScanner v0.11.1 — второе подтверждение и диагностика Qwen

Исправлено пропущенное центральное окно «Телепортироваться в зону ...?».
Первый F выбирает свиток, второй F отправляется только по свежему окну
с точным назначением, «Отмена» и золотой «F OK». Второе подтверждение выдаётся
однократно, затем заново отсчитывается ожидание загрузки/прибытия. Оно не
требует яркого заголовка карты за затемнением. Свободные нажатия F не добавлены.

Подтверждённый застой наземного пути теперь требует поворота/нового вида,
а не простого переключения между соседними путями перед той же стеной.
Правила уже начатого сбора не менялись: причину описанной отмены по полученному
журналу установить нельзя. В нём зарегистрированы три собственных результата
первого ресурса; последующее начало/отмена эфира не подтверждены этими событиями.

У Qwen в этом запуске были ошибки разбора и ни одного принятого ANALYZER_PLAN.
Размер передаваемого изображения уменьшен с 960 до 640 пикселей, контекст
увеличен с 4096 до 8192, предел ответа — с 220 до 512 токенов. Обработка JSON
принимает также корректное ограждение ```json с прежней строгой проверкой схемы.
Пустой/обрезанный ответ не используется: журнал сообщает done_reason,
output_tokens, thinking_chars и длительность без содержимого кадра/рассуждений.
ANALYZER «готов» теперь появляется после первого проверенного ответа.
ANALYZER_RESULT показывает успешный разбор и возраст, ANALYZER_PLAN — принятие
актуальной подсказки. Исправление параметров ещё нужно проверить на настоящем
Ollama пользователя; точная причина прежнего пустого ответа пока не доказана.

В новой папке выполните SETUP.bat, затем SETUP_ANALYZER.bat и START.bat.
Уже скачанная Qwen используется из кэша Ollama; повторно скачивать веса обычно
не потребуется. Lua совместим с v0.10.2/v0.11.0. Камера по умолчанию 940 мс.

## Установка

1. Закройте прежний бот и отдельный VisionObserver. Распакуйте новую папку.
2. Выполните `SETUP.bat`. Нужен Python x64 3.10–3.13, предпочтительно 3.12.
   Если Python Launcher не видит 3.12: `py install 3.12`.
3. **Выполните `SETUP_ANALYZER.bat`.** Он устанавливает официальный Ollama
   через winget, если тот отсутствует, скачивает `qwen3-vl:4b` (около 3,3 ГБ)
   и проверяет настоящий ответ модели на тестовом изображении. Ollama нужен
   версии 0.12.7 или новее. Если winget недоступен, установите Ollama с
   https://ollama.com/download/windows и повторите BAT.
4. В конце установки появится результат в `analyzer_model_info.json`.
   Если загрузка в VRAM не подтверждена, проверьте драйвер NVIDIA и Ollama:
   выполнение на CPU может быть слишком медленным. На RTX 4080 модель делит
   видеопамять с игрой; реальная скорость и свободная память зависят от настроек.
5. Запустите `START.bat`. Включены «Локальный анализатор Ollama» и
   «ИИ-навигация». Кнопки «Анализатор» / «Состояние ИИ» показывают их состояние.
   При первом рабочем кадре журнал должен показать `ANALYZER: ... модель готова`.
   `ANALYZER_PLAN` означает, что ответ ещё подходит текущему виду.
6. Нужны прежние Npcap, ViGEmBus, Tesseract и приёмник Lua в профиле G HUB.
   **Lua совпадает с v0.10.2: повторно менять его не нужно, если он уже заменён.**
   Для более старого Lua используйте файл из этой папки и снова включите G9.
   Отключите физический F710/его приёмник. Ctrl+F8 — запуск, Ctrl+F9 — стоп.

Веса Qwen хранятся в кэше Ollama вне папки бота. Удаление папки бота их не
удаляет; повторный `pull` использует кэш. Ollama должен оставаться запущенным.
Две прежние ONNX-модели уже находятся в архиве. Новый PyTorch/CUDA в Python
ставить не требуется: ONNX работает через DirectML, Qwen обслуживает Ollama.

## Что изменилось в движении

Раньше доли скалы и перепады относительной глубины в трёх крупных полосах могли
объявлять проход между скалами обрывом. Теперь строится сетка видимой поверхности
и несколько связных путей от ближайшего участка земли. Ступени относятся к
земле. Контур скалы сам по себе не запрещает весь сектор.

Для предложений пути используется порог сегментации 0,28; уверенность сохраняется
и видна в журнале. Слабый вариант ограничивает скорость до 0,35 без подтверждения
анализатором. Это расширяет поиск дороги, но не превращает сомнительную текстуру
в доказанный проход. Если модель выделила персонажа, начало привязывается к его
ногам; иначе используется оценочная точка. Журнал различает эти случаи.

Рядом с видимым фиолетовым кибелиском сначала ищется наземный выход, до 25 с:
ресурсы за стеной временно не тянут маршрут прямо в скалу и не вызывают пробный
взлёт. При подтверждённом удалении от кибелиска обычный поиск возвращается раньше.
Поворот и движение ведёт один локальный контроллер. Пять секунд подтверждённого
отсутствия смещения откладывают неудачный вариант пути на восемь секунд.

Анализатор получает снимок с закрытыми панелями HUD/чата и пронумерованными
вариантами. Он может выбрать только существующий номер; сам кнопки не нажимает.
Обработка идёт отдельно от цикла движения. Возраст более 8 с, сильное изменение
кадра, направления или наклона отзывают подсказку. Ошибка подключения не вызывает
ожидания нейросети: остаётся геометрическая навигация. Модель может ошибаться;
её ответ не является подтверждением безопасности дороги.

Если свежий ответ видит стену или возможный край без подходящего маршрута,
он запрещает шаг вперёд на короткую проверку; через 1,5 с запускается смена
цели/ракурса. Отрицательный ответ не превращается в бесконечное ожидание.

## Эфир и сбор

Подписи около центра экрана проверяются раньше периферийных зелёных компонентов.
Тусклый вариант цвета проверяется вместе с обычным, с прежней строгой проверкой
формы слова. После Alt, если локальное слежение потеряло изменившуюся подпись,
выполняется повторный поиск свежего слова поблизости. Подсказка Qwen только
задаёт область для такой проверки: одного ответа нейросети для клика недостаточно.

Правила уже начатого сбора, сетевых ID и одиночного клика по ромбику сохранены.
Наземный планировщик не управляет при подтверждённом сборе/полёте, удерживаемом
ресурсе, открытой карте, защите и возврате наклона. Калибровка по умолчанию —
940 мс; сохранённое вручную значение при переносе настроек остаётся вашим.

## Как увидеть, что распознано

`CHECK_ROUTES.bat` открывает выбор игрового снимка и сохраняет `route_preview.png`
с зелёными путями и красными номерами. Он не двигает персонажа и не нажимает
игровые кнопки. Если зелёная линия проходит через стену или в пустоту, это ошибка
предложения пути; такая картинка помогает проверить восприятие отдельно от игры.
`CHECK_SCENE.bat` по-прежнему показывает семантику/относительную глубину.

Подключение Qwen использует только `http://127.0.0.1:11434`, без облачного API.
Кадры анализируются локальным Ollama; установка скачивает приложение и веса.
Перенаправления на другой сервер запрещены. Включённый анализатор не означает,
что каждый его ответ успевает попасть в управление: устаревший ответ отбрасывается.

## Практические пределы

Нет полной 3D-карты столкновений, измерения метров по монокулярной глубине,
памяти всех дорог или гарантии выхода из любой пещеры. Собственные XYZ должны
действительно прийти из сети; при их отсутствии точное место/высота не выдумываются.
Быстрый обход, выбор перелёта и возврат карты остаются ограниченными процедурами,
а не свободными командами языковой модели. Возврат через карту по умолчанию
направлен в активированный «Временный приют»; это не доказывает удобство его выхода.

Проверки описаны в `VALIDATION_RU.md`. Живой проход из приюта и скорость Qwen
одновременно с игрой здесь не проверялись. Первый тест делайте в знакомом месте;
в журнале нужны `GROUND_ROUTE`, `CAMP_EXIT`, `ANALYZER` и `ANALYZER_PLAN`.

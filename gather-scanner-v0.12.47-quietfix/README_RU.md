# QUIET FIX — исправление Windows-упаковки отдельного теста

В предыдущем ZIP были TEST_MAP_QUIET.py и test_map_quiet.py. На Windows
имена совпадают без учёта регистра, и тестовый файл мог заменить основную
программу. Это ошибка упаковки; по такому запуску клик проверить было нельзя.

В новом архиве основной файл называется quiet_click_run.py, запускатель —
RUN_QUIET_CLICK.bat. Файлы unit-тестов в архив не включены. Все пути проверены
на уникальность без учёта регистра, запускатель проверен по содержимому ZIP.

## Запуск

1. Бот закройте. Распакуйте архив в его папку с START.bat.
2. Если GHUB_MAP_QUIET_TEST.lua из предыдущего архива уже установлен
   и включён G9, Lua оставьте как есть — он не менялся.
   Иначе вставьте GHUB_MAP_QUIET_TEST.lua: Save & Run, затем G9.
3. Запустите RUN_QUIET_CLICK.bat. За 8 секунд переключитесь в игру,
   откройте карту и наведите курсор на доступную точку рядом.
4. Подождите примерно 20 секунд от запуска, не двигая курсор/окно/карту.
   После этого закройте M и проверьте путь.
5. Пришлите map_quiet_probe.log из той же папки и результат.

Макрос AION_MAP_RMB, G5 и Num Lock оставьте как есть. Num Lock не нажимается.
Это отдельный тест: рабочий бот с этим временным Lua запускать не нужно.
ACK означает приём команды. Затем 2 секунды тишины канала, один PlayMacro,
и наблюдение Windows о кнопках мыши. Карта не закрывается программой,
курсор не перемещается, нет OCR/стика Xbox. Фокус/курсор/границы проверяются,
при их изменении или прерывании ожидания отложенный вызов отменяется.

Рабочие Python v0.12.47, настройки и макрос не меняются. Старые тестовые
файлы удалять не требуется: новый запускатель использует новое имя программы.
Лог сохраняется локально. Успешный автоматический путь в игре ещё не доказан.

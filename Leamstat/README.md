# Darkleam — публичная статистика Aion 2

Автообновление профиля **Darkleam / EU Quai** через GitHub Actions **раз в час, в :17 UTC**.

Файлы [data/latest.json](data/latest.json), [data/stats.html](data/stats.html), [data/boards.html](data/boards.html) и остальные в `data/` **перезаписываются**, датированные архивы не сохраняются. При ошибке запроса последняя успешная выгрузка остаётся.

Запустить вручную: **Actions → Darkleam - hourly refresh → Run workflow**.

⚠️ Публичные данные персонажа хранятся в публичном репозитории; старые версии остаются в истории Git.
